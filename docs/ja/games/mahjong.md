# 麻雀ソリティア

**目的：** 同じ牌を2枚ずつ組にして、すべて取りのぞきます。

上に何も重なっておらず、左 **か** 右があいている牌は **取れる牌** です。取れる同じ牌を2枚タップすると、取りのぞけます。**花牌** はどの2枚でも組になり、**季節牌** もどの2枚でも組になります。数字の牌にはすみに小さな算用数字が（風牌には E/S/W/N が）書いてあるので、漢数字が読みにくくても大丈夫です。

かんたんとふつうでは、**取れない牌はうす暗く** なります。**ヒント** は組になる2枚をふちどりで示し、**一手戻す** は最後に取った2枚を元に戻し、**シャッフル** は手づまりのときに残りの牌をならべ直します。

| むずかしさ | 牌の数 | シャッフル |
|---|---|---|
| かんたん | 48（塔） | 何回でも |
| ふつう | 96（とりで） | 3回 |
| むずかしい | 144（定番の亀） | 1回 |

どのならべ方も、**必ず解ける** ように作られています。
