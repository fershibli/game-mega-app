# ルドー

🌐 [English](../../en/games/ludo.md) · [Português](../../pt-BR/games/ludo.md) · [Español](../../es/games/ludo.md) · [Français](../../fr/games/ludo.md) · [Italiano](../../it/games/ludo.md) · [Deutsch](../../de/games/ludo.md) · [Русский](../../ru/games/ludo.md) · **日本語** · [中文](../../zh-CN/games/ludo.md) · [العربية](../../ar/games/ludo.md)

2～4人で遊ぶすごろく型のレースゲームです。あなたと、1～3人のコンピューターが対戦します。十字形の盤の四隅に家があり、それぞれ4つのコマが待っています。サイコロを振ってコマを出し、盤をひと回りしてから自分の色の通路を中央まで進みます。4つのコマを先に中央に入れた人の勝ちです。

あなたは左下の**青**で、先に始めます。ゲームの前に「**何人で遊びますか？**」と聞かれます（2・3・4席、つまりコンピューターは1・2・3人）。選んだ人数はアプリが覚えています。色ごとに記号（丸・三角・四角・ひし形）もついているので、色を見分けなくても遊べます。

**交代で遊ぶ（このスマホで）:** コンピューターなしで2〜4人が、それぞれの色で遊びます。最初に何人で遊ぶかを聞かれます。コンピューターと遊ぶときは、あなたと残りの席がコンピューターです。

## 遊び方

- 盤の真ん中の**サイコロ**（または「**振る**」ボタン）をタップします。
- 動かせるコマには丸い印がつきます。そのコマか、止まるマスをタップします。
- 動かし方が1つしかないときは、少し待つとコマが自動で動きます。動かせないときは次の人の番になります。
- 「**一手戻す**」で最後の選択に戻れます（サイコロの目は同じです）。「**ヒント**」はよい手に印をつけます。

## ルール

- 家からスタートのマスにコマを出すには**6**が必要です。
- コマは時計回りに盤をひと回りし、そのあと自分の通路に入ります。中央にはぴったりの目で入ります。
- 相手のコマがいるマスに止まると、そのコマを**取って**家に戻せます。自分のコマどうしは同じマスに並べます。
- **6**が出たらもう一度振れます。

## 選べるルール

- **クラシック**：スタートのマスと**星**のマスは安全で、そこでは取られません。6が3回続くとその番は終わりです。
- **シンプル**：安全なマスはなく、6が続いても制限はありません。

## レベル

- **かんたん**：コンピューターはでたらめにコマを動かします（ただし最後の1手は逃しません）。
- **ふつう**：取れるときは取り、次にコマを出し、次にいちばん先のコマを進めます。
- **むずかしい**：次の人がどの目を出しそうかも考え、コマを危険から遠ざけます。

## コツ

- クラシックでは星のマスは安全です。待つのにちょうどいい場所です。
- 自分のコマの1～6マス後ろにいる相手のコマは、次の目で取りに来るかもしれません。
- 6で新しいコマを出しておくと、あとで選べる手が増えます。
