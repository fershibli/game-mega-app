# チェッカー

🌐 [English](../../en/games/checkers.md) · [Português](../../pt-BR/games/checkers.md) · [Español](../../es/games/checkers.md) · [Français](../../fr/games/checkers.md) · [Italiano](../../it/games/checkers.md) · [Deutsch](../../de/games/checkers.md) · [Русский](../../ru/games/checkers.md) · **日本語** · [中文](../../zh-CN/games/checkers.md) · [العربية](../../ar/games/checkers.md)

あなたとコンピューターの二人で遊ぶボードゲームです。駒は黒いマスを斜めに進みます。相手の駒のすぐ後ろが空いていれば、飛び越えてその駒を取れます。相手の端まで進んだ駒は**キング**になり、金色の王冠がつきます。コンピューターの駒がなくなるか、動けなくなればあなたの勝ちです。

**交代で遊ぶ（このスマホで）:** コンピューターなしで、二人で対戦することもできます。盤は回転せず、どちらの番かが画面に表示されます。

## 遊び方

- 自分の駒をタップすると、動けるマスが光ります。そのどれかをタップします。
- **取れるときは必ず取ります。** 取れる駒には丸い印がつきます。
- 一度に何個も取るときは、最後のマスをタップします。行き方が何通りもあるときは、止まるマスを順番にタップします。
- **一手戻す**で自分の最後の手(とコンピューターの返し手)を取り消せます。**ヒント**はよい手を教えてくれます。
- キングだけが動いて駒を取らない手がそれぞれ25手続くと引き分けになり、ゲームが終わらなくなることはありません。

## 選べるルール

- **ブラジル式チェッカー**(8×8、各12個): 普通の駒は1マス前に進み、前にも後ろにも取れます。キングは「飛ぶ」ことができ、斜めにいくつでも進んで取れます。一番多く取れる手を選ばなければなりません。取る途中で最後の列を通っただけの駒は、そこで止まったときだけキングになります。
- **国際ドラフツ**(10×10、各20個): ブラジル式と同じルールで、盤が大きくなります。
- **英国式チェッカー**(8×8、アメリカ式とも): 普通の駒は前にだけ進んで取ります。キングは斜めのどの方向にも1マス動きます。取るのは必須ですが、どの取り方を選んでもかまいません。キングになった駒はその手で止まります。黒が先手なので、ここではあなたが黒い駒を使います。
- **イタリア式チェッカー**(8×8、盤を回して右手の隅に遊ぶマスがきます): 普通の駒は前にだけ取れ、キングを取ることはできません。キングは1マス動きます。一番多く取れる手が必須で、同じ数ならキングで取る手、次にキングを多く取る手が優先です。
- **ロシア式チェッカー**(8×8): 普通の駒は後ろにも取れ、キングは飛び、取り方は自由に選べます。取る途中でキングになった駒は、キングとして取り続けます。

## レベル

- **かんたん**: 2手先まで読み、ときどき不注意な手を指します。覚えるのにぴったりです。
- **ふつう**: 4手先くらいまで読みます。
- **むずかしい**: 1秒以内にできるだけ深く読みます。

## コツ

- 自分のいちばん後ろの列はできるだけ動かさないでおきましょう。相手がキングになるのを防げます。
- 盤の真ん中の駒は、端の駒より強いです。
- 動かす前に、その駒が次の手で取られないか確かめましょう。
