# 四目並べ

🌐 [English](../../en/games/fourinrow.md) · [Português](../../pt-BR/games/fourinrow.md) · [Español](../../es/games/fourinrow.md) · [Français](../../fr/games/fourinrow.md) · [Italiano](../../it/games/fourinrow.md) · [Deutsch](../../de/games/fourinrow.md) · [Русский](../../ru/games/fourinrow.md) · **日本語** · [中文](../../zh-CN/games/fourinrow.md) · [العربية](../../ar/games/fourinrow.md)

7列6段の穴があいた、立てた木の台で遊ぶ二人用のゲームです。あなたは明るい色のコマで先手、コンピューターは暗い色のコマです。縦・横・斜めのどれかに、自分のコマを先に四つ並べたほうの勝ちです。

**交代で遊ぶ（このスマホで）:** コンピューターなしで、二人で対戦することもできます。盤は回転せず、どちらの番かが画面に表示されます。

## 遊び方

- 列のどこでも（盤の上から下まで）タップすると、コマがいちばん下の空いた穴まで落ちます。
- いっぱいになった列にはもう入れられません。42個の穴がすべて埋まって四つ並ばなければ引き分けです。
- 勝った列は強調表示されます。
- **一手戻す**で自分の最後の手（とコンピューターの応手）を取り消せます。**ヒント**はよい列に色をつけます。

## レベル

- **かんたん**：勝てるときは必ず勝ち、あなたの勝ちはたいてい止めますが、それ以外は2手先までしか読まず、ときどき適当な列に落とします。
- **ふつう**：6手先まで読みます。
- **むずかしい**：約3分の2秒でできるだけ先まで読みます。勝つのはとても難しいです。

## コツ

- 真ん中の列がいちばん価値があります。四つ並びの線が最も多く通るからです。
- コマを落とす前に、そのすぐ上にコンピューターが打って勝たないか確かめましょう。
- 脅威を二つ同時に作りましょう。たとえば片方をもう片方のすぐ上に。コンピューターは一つしか止められません。
