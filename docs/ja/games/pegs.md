# ペグ・ソリテール

🌐 [English](../../en/games/pegs.md) · [Português](../../pt-BR/games/pegs.md) · [Español](../../es/games/pegs.md) · [Français](../../fr/games/pegs.md) · [Italiano](../../it/games/pegs.md) · [Deutsch](../../de/games/pegs.md) · [Русский](../../ru/games/pegs.md) · **日本語** · [中文](../../zh-CN/games/pegs.md) · [العربية](../../ar/games/pegs.md)

木の盤に並んだ玉で、何百年も遊ばれてきた、ひとりで楽しむ静かなパズルです。

## 遊び方
玉をタップし、まっすぐ（上・下・左・右。ななめは不可）**2つ先**の空いた穴をタップします。玉はとなりの玉を跳び越え、跳び越えられた玉は盤から取り除かれます。跳べる玉がなくなるまで続けます。

- **玉が1つだけ残った：** 勝ちです！
- **最後の1つが印の穴（小さな金色の輪）に残った：** パーフェクト。
- **跳べないまま玉がいくつか残った：** ゲームはおだやかに終わり、残った数を教えてくれます。

**一手戻す** は1回ずつ何回でも戻せます。**はじめから** で最初の盤にもどります。

## 盤の種類
- **イギリス式の盤** — 十字形の33個の穴。中央以外はすべて玉で埋まっています。パーフェクトは最後の玉が中央に残ること。
- **フランス式の盤** — 37個の穴：十字形に内側の四すみの穴が加わります。上のまん中の穴が空いた状態で始まり、パーフェクトは最後の玉が下のまん中の穴に残ること（この盤では中央で終わることはできません）。

## レベル
| レベル | 始まり | 手助け |
|---|---|---|
| かんたん | 途中まで解かれた盤（玉10〜12個）。かならず1つまで減らせます | 跳べる玉に輪がつき、玉を選ぶと跳び先の穴が光ります |
| ふつう | すべて埋まった盤 | かんたんと同じ印 |
| むずかしい | すべて埋まった盤 | 印なし |

## コツ
- ほかの玉から離れたところに玉をひとつだけ残さないように。となりのない玉はもう取れません。
- 十字の腕を1本ずつ片づけ、まん中へもどってきましょう。
- 一手戻すは何度でも使えます。思いついた手を試して、だめなら戻して別の手を。
