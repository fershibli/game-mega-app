# スパイダー

🌐 [English](../../en/games/spider.md) · [Português](../../pt-BR/games/spider.md) · [Español](../../es/games/spider.md) · [Français](../../fr/games/spider.md) · [Italiano](../../it/games/spider.md) · [Deutsch](../../de/games/spider.md) · [Русский](../../ru/games/spider.md) · **日本語** · [中文](../../zh-CN/games/spider.md) · [العربية](../../ar/games/spider.md)

2組のトランプ（104枚）を10列に並べる一人遊びです。**同じマークでキングからエースまで**の列を作ります。そろった列は自動で場から消えます。8列すべてそろえたら勝ちです。

## 遊び方

- 54枚が配られます。最初の4列に6枚ずつ、残りの列に5枚ずつで、各列のいちばん下のカードだけが表向きです。
- カードは、マークに関係なく**ひとつ大きい数**のカードの上に置けます（6はどの7の上にも置けます）。空いた列にはどのカードや列でも置けます。
- いっしょに動かせるのは、**同じマーク**で順番に並んだカードだけです。カードをタップすると、上のカードといっしょにいちばんよい場所へ動きます。もう一度タップすると次の場所を試します。
- 裏向きのカードが出てくると、自動で表になります。
- **山札**（親指側の角）をタップすると、各列に1枚ずつ新しい列が配られます。配れるのは5回です。昔からのルールどおり、**空いた列がないとき**だけ配れます。試すと、先に空いた列を埋めるように教えてくれます。
- **一手戻す**で手を戻し、**ヒント**で役に立つ手（または配ること）を見せます。役に立つ手がなく山札も空のときは、それを知らせます。何手か戻す、あきらめる、もう少し探す、から選べます。

## 選べるルール

マークの数がむずかしさなので、別にレベルは選びません。

- **1種類のマーク**：すべてスペード。いちばんやさしく、覚えるのに最適です。
- **2種類のマーク**：スペードとハート。どこに置くか、よく考える必要があります。
- **4種類のマーク**：4つのマークすべて。本格的な挑戦で、勝てないゲームも多くあります。

## コツ

- いちばん大事なのは裏向きのカードを表にすることです。カードが出てくる手を選びましょう。
- できるだけ同じマークの上に重ねましょう。マークがまざった列はいっしょに動かせません。
- 空いた列はとても貴重です。カードを1枚置くだけでなく、並べ直すのに使いましょう。
- 新しい列を配る前に、役に立つ手をすべて打ちましょう。新しいカードが列をふさいでしまいます。
