# ピンボール

🌐 [English](../../en/games/pinball.md) · [Português](../../pt-BR/games/pinball.md) · [Español](../../es/games/pinball.md) · [Français](../../fr/games/pinball.md) · [Italiano](../../it/games/pinball.md) · [Deutsch](../../de/games/pinball.md) · [Русский](../../ru/games/pinball.md) · **日本語** · [中文](../../zh-CN/games/pinball.md) · [العربية](../../ar/games/pinball.md)

のんびり遊べるピンボール台です。ボールはゆっくり転がるので、落ちてくるのがよく見えます。

## 遊び方
- **ボールを出す** をタップすると、右下のばねの上でボールが待ちます。**▲ 発射** を押すと、ボールが通路をのぼって台に出ていきます。「ふつう」「むずかしい」では、発射を長く押すほど強く飛びます。「かんたん」では強さは自動です。
- 大きな **◀ 左** と **右 ▶** のボタン（または台の左半分・右半分）を **押している間**、そちらのフリッパーが上がります。はなすと下がります。落ちてくるボールを受けて、上へはね返しましょう。
- ボールがフリッパーの間から落ちるとアウトです。**一時停止** でいつでも止められます。アプリを離れても止まります。

## 点数
| もの | 点数 |
|---|---|
| 丸いバンパー | 100 |
| フリッパーの上のオレンジのはね返し | 25 |
| 上の星（光ります） | 50 |
| 星が4つとも光る | ボーナス +500（星はまた消えます） |
| 上のレーン（光ります） | 30 |
| 3つのレーンが全部光る | そのボールが落ちるまで得点 ×2 |
| 青い倒れるターゲット | 75 |
| 3つのターゲットを全部たおす | ボーナス +400（ターゲットはまた立ちます） |
| 左のランプ（ボールがぐるっと回って左のフリッパーへ下りてきます） | 300 |

レベルごとの最高点が記録されます。

## レベル
| レベル | ボール | 速さ | ボールセーバー |
|---|---|---|---|
| かんたん | 5 | ゆっくり | 最初の12秒 |
| ふつう | 4 | ふつう | 最初の6秒 |
| むずかしい | 3 | 少し速い | なし |


**ボールセーバー** があると、出してすぐに落ちたボールはもどってきて、数に入りません。
