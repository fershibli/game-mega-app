# バックギャモン

**目的：** 明るい色の駒15個を盤の上で進めて自分の陣地（ポイント1〜6、右下）に集め、コンピューター（暗い色の駒）より先に全部を上がらせる（盤の外に出す）ことです。

**交代で遊ぶ（このスマホで）:** コンピューターなしで、二人で対戦することもできます。盤は回転せず、どちらの番かが画面に表示されます。 サイコロはそれぞれが自分で振ります。

盤は昔ながらの **横向き** です。上に 13→24、下に 12→1 のポイントがならび（あなたの陣地は右下）、まん中を **バー** が通り、右側に上がった駒を置く **トレイ** があります（あなたのトレイは下側）。2本指で拡大して、盤を動かせます。**回転** を押すと盤が縦向きになり、画面いっぱいに大きな駒で表示されます。このときは、ポイント 12→1 が左の列を上から下へ（あなたの陣地は左下）、13→24 が右の列を上から下へならび、バーはまん中を横切り、トレイは下にあります。選んだ向きはアプリが覚えています。

**遊び方：** **サイコロをふる** をタップします。動かせる駒は **黄色** に光ります。駒をタップすると、動かせる先が **緑** に光るので、そこをタップします。動かせる先が1か所しかない駒は、すぐにそこへ動きます。サイコロを全部使ったら **完了** をタップします。**一手戻す** で、その番の最初に戻れます。上がるときはトレイをタップします。

正式なルールどおりです。できるときは2つのサイコロの目を両方使わなければなりません（片方しか使えないときは大きいほう）。ゾロ目は4回動かせます。1つだけぽつんと置かれた相手の駒（「ブロット」）にはヒットでき、ヒットされた駒はバーに送られます。バーにある駒は、ほかの駒より先に盤に戻さなければなりません。負けた側が1つも上がっていなければ *ギャモン*（2倍の勝ち）、負けた側の駒がまだバーか勝った側の陣地に残っていれば *バックギャモン*（3倍の勝ち）になります。ダブリングキューブはありません。

コンピューターの強さ：*かんたん* はよく、でたらめな手を打ちます。*ふつう* は、打てる手をすべてくらべます（レースの進み、安全なポイント、ブロット、プライム、アンカー）。*むずかしい* は、さらに相手の次のサイコロ21通りすべてを考えて打ちます。
