# 五目並べ

🌐 [English](../../en/games/gomoku.md) · [Português](../../pt-BR/games/gomoku.md) · [Español](../../es/games/gomoku.md) · [Français](../../fr/games/gomoku.md) · [Italiano](../../it/games/gomoku.md) · [Deutsch](../../de/games/gomoku.md) · [Русский](../../ru/games/gomoku.md) · **日本語** · [中文](../../zh-CN/games/gomoku.md) · [العربية](../../ar/games/gomoku.md)

15路の盤の交点で遊ぶ二人用のゲームです。あなたは黒で先手、コンピューターは白です。縦・横・斜めのどれかに、すき間なく五つ以上の石を先に並べたほうの勝ちです。

## 遊び方

- 交点をタップすると、石がうすく表示されます。同じ交点をもう一度タップすると置かれます。別の交点をタップすれば置き直せます。
- 最後に打たれた石には小さな輪がつき、勝った列は強調表示されます。
- **一手戻す**で自分の最後の手（とコンピューターの応手）を取り消せます。**ヒント**はよい交点を示します。

## ルール

- 自由ルール：五つ以上並べば勝ちで、六つ以上でもかまいません。
- 黒に対する競技ルールの禁じ手（三三、四四、長連）は**使いません**。そのため先手の黒が有利です。
- 盤が埋まったら引き分けです。

## レベル

- **かんたん**：いちばんよさそうな交点を選びますが、わざと悪い手を打つこともあり、四を止め忘れることさえあります。
- **ふつう**：自分の四は必ず五にし、あなたの四は必ず止め、数手先まで読みます。
- **むずかしい**：さらに深く読み、四を続けて勝つ手順も探します。すべて1秒以内です。

## コツ

- **活三**（両端が空いた三つ並び）はすぐに止めましょう。放っておくと止められない活四になります。
- 二つの脅威を同時に作れば勝ちです。一手で四と活三を作ることをねらいましょう。
