# フリーセル

🌐 [English](../../en/games/freecell.md) · [Português](../../pt-BR/games/freecell.md) · [Español](../../es/games/freecell.md) · [Français](../../fr/games/freecell.md) · [Italiano](../../it/games/freecell.md) · [Deutsch](../../de/games/freecell.md) · [Русский](../../ru/games/freecell.md) · **日本語** · [中文](../../zh-CN/games/freecell.md) · [العربية](../../ar/games/freecell.md)

最初から**すべてのカードが表向き**の一人遊びです。先を読む力がすべてです。**マークごとにエースからキングまで**、4つの山を作りましょう。ほとんどの配り方は勝てますが、このアプリでは必ず勝てる配り方だけが出ます。

## 遊び方

- 52枚のカードが8列に配られます。その上に**4つのフリーセル**（親指側）と、マークごとの**4つの組札置き場**があります。
- 列では、**ひとつ大きい数で色のちがう**カードの上に重ねます（赤の6は黒の7の上）。空いた列にはどのカードでも置けます。
- フリーセルには**1枚ずつ**カードを置いて、しばらくよけておけます。
- カードをタップすると、いちばんよい場所へ動きます（まず組札、次に別の列、フリーセル、最後に空いた列）。もう一度タップすると次の場所を試します。
- 順番に並んだ何枚かのカードは、運ぶ場所があればまとめて動かせます。（空きセル＋1）枚で、空いた列ひとつごとに2倍になります。足りないときは、今動かせる枚数を教えてくれます。
- すべての列が順番にそろうと、**自動で仕上げる**ですべてのカードを組札へ送れます。
- **一手戻す**で手を戻せます。**ヒント**は、勝てる道すじの次の一手をソルバーに聞いて見せます。毎回の手のあと、まだ勝てるかを調べ、勝てなくなったら知らせます。戻す、あきらめる、もう少し探す、から選べます。

## レベル

どの配り方も、表示する前にソルバーで確かめてあるので、必ず勝てます。

- **かんたん**：4つのうち2つのフリーセルだけでソルバーが勝てる配り方。4つ使えれば余裕があります。
- **ふつう**：フリーセルが3つ必要な配り方。
- **むずかしい**：フリーセル4つすべてと、しっかりした計画が必要な配り方。

## コツ

- まずエースと2を自由にしましょう。ほかのカードの下を探します。
- フリーセルはできるだけ空けておきましょう。全部うまると何もできなくなります。
- 空いた列はフリーセルより価値があります。動かせる枚数が2倍になります。
- 動かす前に数手先を考えましょう。出てくるカードはどこへ行けるでしょう？
