# 数字あわせ

🌐 [English](../../en/games/merge.md) · [Português](../../pt-BR/games/merge.md) · [Español](../../es/games/merge.md) · [Français](../../fr/games/merge.md) · [Italiano](../../it/games/merge.md) · [Deutsch](../../de/games/merge.md) · [Русский](../../ru/games/merge.md) · **日本語** · [中文](../../zh-CN/games/merge.md) · [العربية](../../ar/games/merge.md)

数字のタイルが並んだ盤です。全部のタイルを一方へすべらせます。同じ数字がぶつかると足し算されて1つになります（2 + 2 で 4、4 + 4 で 8……）。

## 遊び方
- 指でなぞるか矢印を押して、すべてのタイルを動かします。
- 動かすたびに、空いたマスに 2（ときどき 4）が出ます。
- 目標の数字を作りましょう。そのあとは、もっと点数をねらうか、そこで終わるかを選べます。
- どのタイルも動かせなくなったら終わりです。時間制限はありません。

## レベル
- **やさしい：** 256 を作る。
- **ふつう：** 512 を作る。
- **むずかしい：** 1024 を作る。

## コツ
- いちばん大きい数字を角において、だいたい2つの方向にすべらせましょう。
