# タングラム

🌐 [English](../../en/games/tangram.md) · [Português](../../pt-BR/games/tangram.md) · [Español](../../es/games/tangram.md) · [Français](../../fr/games/tangram.md) · [Italiano](../../it/games/tangram.md) · [Deutsch](../../de/games/tangram.md) · [Русский](../../ru/games/tangram.md) · **日本語** · [中文](../../zh-CN/games/tangram.md) · [العربية](../../ar/games/tangram.md)

7つの平らなピース（大きい三角形2つ、中くらい1つ、小さい2つ、正方形、平行四辺形）で絵を作ります。7つのピースを重ねずに使って、形をうめましょう。

## 遊び方
- ピースをドラッグして動かし、タップして回します。
- **裏返す**で平行四辺形を裏返します。
- ピースは近づけると自動でぴったりはまります。**ヒント**は1つ置いてくれます。**最初から**で全部もどります。

## レベル
- **やさしい：** 形の中に、すべてのピースの線がかいてあります。
- **ふつう：** 3つのピースがかいてあります。
- **むずかしい：** 形だけです。

## コツ
- 大きい三角形2つから置きましょう。形のほとんどをうめてくれます。
