# 将棋

🌐 [English](../../en/games/shogi.md) · [Português](../../pt-BR/games/shogi.md) · [Español](../../es/games/shogi.md) · [Français](../../fr/games/shogi.md) · [Italiano](../../it/games/shogi.md) · [Deutsch](../../de/games/shogi.md) · [Русский](../../ru/games/shogi.md) · **日本語** · [中文](../../zh-CN/games/shogi.md) · [العربية](../../ar/games/shogi.md)

日本の将棋です。いちばんの特徴は、**取った駒が自分の駒になる**こと。あとで自分の駒として盤に打てます。

## ルールの選択

- **本将棋（9×9）**：ふつうの将棋で、駒はそれぞれ20枚。
- **五五将棋（5×5）**：小さな盤に、各種類1枚ずつ（玉・飛・角・金・銀・歩）。すぐ終わるので練習にぴったりです。

## 盤と駒

- 駒は**マスの中**に置きます。駒の色は同じで、あなたの駒は**上向き**、コンピューターの駒は下向き（少し濃い色）です。
- あなたが下側から先に指します。
- 駒の**点**はその方向に一歩、**矢印**はどこまでも進めることを表します。赤い字は成った駒です。

| 駒 | 動き方 | 成ると |
|---|---|---|
| 玉将 王 / 玉 | どの方向にも一歩。 | — |
| 飛車 飛 | たて・横にどこまでも。 | 竜王 龍：斜めにも一歩。 |
| 角行 角 | 斜めにどこまでも。 | 竜馬 馬：たて・横にも一歩。 |
| 金将 金 | 斜め後ろ以外のどの方向にも一歩。 | 成りません。 |
| 銀将 銀 | 前と斜めに一歩。 | 金と同じ動き（全）。 |
| 桂馬 桂 | 二つ前の左右に跳ぶ（上に点が二つ）。 | 金と同じ動き（圭）。 |
| 香車 香 | まっすぐ前にどこまでも。 | 金と同じ動き（杏）。 |
| 歩兵 歩 | 前に一歩。 | と金 と：金と同じ動き。 |

「駒」ボタンをタップすると、いつでも一覧を大きな絵で見られます。

## 成り

相手側の三段（五五将棋では一段）が**敵陣**で、うすく色がついています。駒が敵陣に入る・敵陣の中で動く・敵陣から出るとき、大きなボタンで「成る」「成らない」を聞きます。成らないと二度と動けない場合（最後の段の歩・香、最後の二段の桂）は自動で成ります。

## 持ち駒を打つ

取った駒は盤の下の**持ち駒**になります。指す代わりに持ち駒をタップし、緑のマスをタップすると、そこに打てます。決まり：

- 打った駒はその場では成れません。
- 成っていない自分の歩を同じ列に二枚置けません（二歩）。
- 歩を打って**すぐに詰ませる**ことはできません（打ち歩詰め）。ほかの駒なら大丈夫です。
- 二度と動けない場所には打てません（最後の段の歩・香、最後の二段の桂）。

## 勝ち方

コンピューターの玉を詰ませれば勝ちです。同じ局面が**四回**現れると（千日手）引き分けです。

## アプリでの遊び方

1. 盤の上の駒か持ち駒をタップすると、行ける場所が緑の点で表示されます。
2. 緑の点をタップします。成るかどうか聞かれたら答えます。
3. 「一手戻す」はあなたの最後の手とコンピューターの応手を取り消し、「ヒント」は良い手を示します。

## レベル

- **かんたん**：一手先だけを見て、よくまちがえます。
- **ふつう**：数手先まで読みます。
- **むずかしい**：1秒以内でできるだけ深く読みます。

## 簡単にしたところ

連続王手の千日手を王手側の負けにするルールは使わず、四回のくり返しはすべて引き分けです。400手に達した対局も引き分けです。入玉の点数計算（持将棋）はありません。

## コツ

- 持ち駒は強力です。取った金や銀を相手の玉の近くに打つと、勝負が決まることがよくあります。
- 自分の玉は金と銀の壁で囲いましょう。
- 成れるときは成るのが基本です。成らない銀や桂のほうが役に立つ場面はまれです。
