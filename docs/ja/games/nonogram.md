# ノノグラム

🌐 [English](../../en/games/nonogram.md) · [Português](../../pt-BR/games/nonogram.md) · [Español](../../es/games/nonogram.md) · [Français](../../fr/games/nonogram.md) · [Italiano](../../it/games/nonogram.md) · [Deutsch](../../de/games/nonogram.md) · [Русский](../../ru/games/nonogram.md) · **日本語** · [中文](../../zh-CN/games/nonogram.md) · [العربية](../../ar/games/nonogram.md)

数字のとおりにぬるパズルです。各行の左と各列の上の数字は、その列でぬるかたまりの長さを順番に表します。かたまりとかたまりの間には、1マス以上の空きがあります。正しくぬると絵があらわれ、完成すると色つきで名前が表示されます。

## 遊び方

- マスをタッチするとぬれます。もう一度タッチすると消えます。
- マスを長押しすると✕がつきます（空いたままとわかったマス）。**しるし**をオンにすると、タッチで✕、長押しでぬります。
- 行や列にそってなぞると、いくつものマスを一度にぬれます（✕もつけられます）。
- ぬったマスが数字と合うと、その列の数字がうすくなります。
- **一手戻す**で直前の変更を取り消します。**ヒント**はまずまちがいを直し、なければ一列だけで決まるマスをぬります。
- 大きな盤は二本指で拡大できます。

## レベル

- **かんたん**：5×5。まちがいは赤で表示されます。
- **ふつう**：10×10。まちがいは赤で表示されます。
- **むずかしい**：15×15。まちがいは表示されません。

どの問題も一列ずつ考えれば解け、当てずっぽうは必要ありません。絵（各サイズ20以上：動物、花、家、船、ティーポットなど）はこのアプリのために描いたものです。合う絵がないときは、ランダムなもようを使います。

## コツ

- 大きな数字から始めましょう。10マスの列に8のかたまりがあれば、まん中の6マスは必ずぬれます。
- 0の列はすべて空きです。✕をつけましょう。
- 空きのマスに✕をつけると、交わる列のヒントになります。
