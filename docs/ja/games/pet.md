# ペットのおともだち

スマホの中の、居心地のいいお部屋に小さなおともだちが住んでいます。好きなときにお世話をしてください。急ぐ必要も時間制限もなく、悪いことは何も起こりません。

## はじめて

10種類のおともだちから1つ選びます：ねこ、いぬ、うさぎ、ひよこ、パンダ、かえる、きつね、ペンギン、ハムスター、かめ。次に名前の候補を1つタップ（または自分で入力）して、**むかえる** をタップします。

## 4つのバー

**ごきげん**、**おなか**、**げんき**、**きれい** は、アプリを閉じていても、とてもゆっくり減ります（満タンから空まで約1日）。20 % より下にはなりません。バーの最初のうすい部分が「空」のしるしです。おともだちは病気にならず、いなくならず、怒ることもありません。バーが低いと、少しねむそう・おなかがすいたように見えて、小さなふきだしを出しますが、あなたに会えるといつも喜びます。

## できること

- **ごはん**：りんご、にんじん、さかな、クッキー。それぞれ大好物があります。
- **なでなで**：指でなでると、小さなハートが出ます。
- **キス** と **手をふる**：キスのおかえしをして、手をふってくれます。
- **おふろ**：あわがいっぱいで、ぴかぴかになります。
- **おやすみ**：部屋が暗くなり、げんきがもどります。好きなときに **おはよう** をタップ。
- **おさんぽ**：お庭をおさんぽします。
- **あそぶ**：じゃんけん、まるばつ（あなたの印はハート、おともだちは足あと。かんたんに打つので、ときどき勝たせてくれます）、ボール。
- **おしゃれ**：リボン、ぼうし、お花、マフラー。

## おともだち・むかえる

確認のあと、いつでも別の種類のおともだちをむかえられます。それまでいた子はお庭で待っていて、同じ画面からいつでも呼びもどせます。だれもいなくなりません。

## 保存

すべてすぐにスマホに保存されます。アプリを閉じても、スマホを再起動しても、ほかのゲームをしても、設定の **新しいゲーム** を押しても、おともだちは消えません。アプリをアンインストールすると消えます。

## ヒント

- 勝ち負けはありません。会いたいときに来てください。
- 指でなでるのが苦手なら、**なでなで** ボタンでもなでられます。
