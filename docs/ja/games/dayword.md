# 今日のことば

🌐 [English](../../en/games/dayword.md) · [Português](../../pt-BR/games/dayword.md) · [Español](../../es/games/dayword.md) · [Français](../../fr/games/dayword.md) · [Italiano](../../it/games/dayword.md) · [Deutsch](../../de/games/dayword.md) · [Русский](../../ru/games/dayword.md) · **日本語** · [中文](../../zh-CN/games/dayword.md) · [العربية](../../ar/games/dayword.md)

かくれたことばを当てましょう。毎日、レベルごとに新しいことばが出ます。その日その言語で遊ぶ人はみんな同じことばです。

## 遊び方

- 日本語では、下のカナの中からタップして、色のついた行にことばを書き、**たしかめる**をタップします。どんな組み合わせでもかまいません。
- すると、文字ごとに下に印がつきます。
  - **●** この文字はことばの中の、この場所にある（やわらかい帯の上に出ます）
  - **○** この文字はことばの中の、別の場所にある（丸で囲まれます）
  - **—** この文字はことばにない（うすくなります）
- ことばに1つしかない文字を2回書いたときは、印がつくのは1つだけです。
- カナのボタンにも同じ印がつきます。いちばん上の**わかっていること**の行には、場所がわかった文字が集まります。
- **ヒント**は、まずカギを出し、次からは**わかっていること**の行に1文字ずつ置きます。
- 今日のことばのあとは、練習のことばになります。**別のことば**でいつでも新しい練習のことばに変えられます。

## レベル

- **やさしい**：3文字、8行。
- **ふつう**：4文字、7行。
- **むずかしい**：5文字、6行。

アルファベットの言語では4〜5文字・5文字・6文字で、キーボードで入力します。中国語は漢字2・3・4文字（むずかしいは四字熟語）です。

## コツ

- ●の文字はそのままにして、○の文字は別の場所に動かしてみましょう。
