# ヘビ

ゆっくり進むやさしいヘビが、マス目の上を動きます。果物（りんご、さくらんぼ、いちご、洋なし）まで連れて行きましょう。1つ食べるごとに1マス長くなります。急ぐ必要はありません。ヘビはゲーム中だけ動き、いつでも一時停止できます。

## 遊び方
- **4つの大きな矢印**（または盤の上で指をすべらせる）で進む向きを決めます。矢印を押すとゲームも始まります。
- **一時停止**でヘビが止まります。設定を開いたりアプリを離れたりしたときも自動で止まります。**続ける**で再開します。
- 長さと、そのレベルの最高記録が表示されます。最高記録は、ほかのゲームを遊んでも消えません。

## レベル
- **かんたん：** とてもゆっくり。端を通り抜けて反対側から出てきます。自分に触れても、しっぽの先が短くなるだけで、ゲームは終わりません。
- **ふつう：** ゆっくり。端は通り抜けられますが、自分に触れると終わりです。
- **むずかしい：** 少し速く、端は壁です。壁か自分に触れると終わりです。

## コツ
- 曲がる向きは早めに決めましょう。ヘビは矢印を2回分まで覚えています。
- 端に沿って進むと、真ん中を長い体のために空けておけます。
