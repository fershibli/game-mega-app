# 囲碁

🌐 [English](../../en/games/go.md) · [Português](../../pt-BR/games/go.md) · [Español](../../es/games/go.md) · [Français](../../fr/games/go.md) · [Italiano](../../it/games/go.md) · [Deutsch](../../de/games/go.md) · [Русский](../../ru/games/go.md) · **日本語** · [中文](../../zh-CN/games/go.md) · [العربية](../../ar/games/go.md)

何千年も前に東アジアで生まれた二人用の盤上遊戯です。あなたは黒石、コンピューターは白石を持ちます。石は線の交点に置き、置いた石は動きません。相手より広く盤を囲むのが目的です。

## 遊び方

- 交点をタップすると石を置きます。13路盤と19路盤では交点が小さいので、1回目のタップで石がうすく表示され、同じ交点をもう一度タップすると置かれます。
- 線でつながった石はひとつのグループになります。グループには、となりに空いた交点（**呼吸点**）が少なくともひとつ必要です。最後の呼吸点をふさがれると、そのグループは**取られ**、盤から取りのぞかれます。
- 相手の石を取れる場合をのぞき、呼吸点がなくなる場所には打てません。
- **コウ**：石をひとつ取られた直後に、同じ場所ですぐに取り返すことはできません。先にほかの場所へ打ちましょう。
- 打つ価値のある所がなければ**パス**をタップします。両者が続けてパスすると対局は終わります。
- 最後に打たれた石には小さな輪がつきます。取った石の数は上に表示されます。
- **一手戻す**で自分の最後の手（とコンピューターの応手）を取り消せます。**ヒント**はよい交点を示します。

## 数え方

- 面積で数えます（中国ルール）：盤上の自分の石と、自分の石だけに囲まれた空き交点が、それぞれ1点になります。
- 白は後手なので6.5点（**コミ**）を加えます。0.5点があるので引き分けはありません。
- 2回のパスのあと、コンピューターが**死に石**（取られるのを避けられない石）を提案します。死に石には×印がつき、地は小さな四角で示されます。グループをタップすると死に石と生き石を切り替えられます。よければ**数える**をタップ。納得できないときは**続ける**をタップして、盤上で決着をつけましょう。

## 盤の大きさ

- **9路盤**：小さくて早い。はじめるのに最適です。
- **13路盤**：作戦の余地が広がります。
- **19路盤**：正式な大きさの盤。二本の指で広げると拡大できます。

## レベル

- **かんたん**：ほぼでたらめに打ちますが、呼吸点がひとつだけの石は取り、自分の石をよく助け、危ない所にはあまり打ちません。ルールを覚えるのに向いています。
- **ふつう**：今の局面から短い想像上の対局を何千回も最後まで打ってみて、いちばんよく勝つ手を選びます（モンテカルロ探索）。考える時間は約3分の1秒です。
- **むずかしい**：同じ探索を約3分の2秒行います。大きな盤では同じ時間で試せる対局が少ないため、コンピューターは弱くなります。

コンピューターは自分の眼を決してつぶしません。置き石はなく、どのレベルでもコミは6.5です。

## コツ

- 隅、辺、中央の順に打ちましょう。隅はいちばん少ない石で囲めます。
- 別々の眼（内側の空き点）がふたつあるグループは、決して取られません。
- 自分のグループの呼吸点がひとつになったら、すぐに助けるか、あきらめましょう。助からない石に石を足し続けないこと。
