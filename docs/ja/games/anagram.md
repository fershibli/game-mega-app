# アナグラム

ことばの文字がばらばらになっています。正しい順にならべましょう！

## 遊び方

- 大きな文字のコマを正しい順にタップします。コマは答えの次の空いた場所に入ります。
- 答えの文字をタップすると、その文字は戻ります。**一手戻す**で最後の文字を戻せます。**まぜる**でコマをまぜ直すと、ことばが見えてくることもあります。
- 正解するとことばの色が変わり、次のことばに進みます。1回は5問です。
- **ヒント**は次の正しい文字を置きます（まちがった文字は先に戻します）。ヒントを使えば必ず最後までできます。
- 同じ文字で辞書の別のことばができたら、それも正解です。

## レベル

- **やさしい**：3文字のことば。カギが出て、最初の文字はもう置いてあります。
- **ふつう**：4文字、カギあり。
- **むずかしい**：5〜6文字、カギなし。最初の**ヒント**でカギが出ます。

ほかの言語では、やさしい4〜5文字、ふつう6〜7文字、むずかしい8文字以上です。中国語は漢字の数で数えます（3、3〜4、4）。

## コツ

- まずカギを読み、「ー」や「ン」の場所を考えてみましょう。
- 自信のある文字から置いて、残りはあとでためしましょう。
