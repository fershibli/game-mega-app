# チャンギ（朝鮮将棋）

🌐 [English](../../en/games/janggi.md) · [Português](../../pt-BR/games/janggi.md) · [Español](../../es/games/janggi.md) · [Français](../../fr/games/janggi.md) · [Italiano](../../it/games/janggi.md) · [Deutsch](../../de/games/janggi.md) · [Русский](../../ru/games/janggi.md) · **日本語** · [中文](../../zh-CN/games/janggi.md) · [العربية](../../ar/games/janggi.md)

チャンギはシャンチーの仲間で、韓国で何百年も遊ばれてきました。盤に川はなく、宮殿の斜めの線をいくつかの駒が使えます。また、指す代わりに**パス**もできます。

## 盤

- 横9本・縦10本の線があり、駒は**交点**に置きます。
- それぞれの側に**宮殿**（X印のある3×3の交点）があります。宮殿の中では、Xの斜めの線にそっても動けます。
- あなたは**青**（楚）で、下側から先に指します。コンピューターは赤（漢）です。
- 将は宮殿の**まん中**から始まります。

## 駒と印

駒には文字と、動き方を表す小さな印があります。

- **点** ＝ 一歩、**点が二つ** ＝ 象の長い跳び
- **矢印** ＝ どこまでも
- **横線つきの矢印** ＝ 駒を一つ飛び越えなければならない
- **白抜きの点** ＝ 宮殿の線の上だけでできる斜めの一歩

| 駒 | 動き方 |
|---|---|
| 将 楚 / 漢（いちばん大きい駒） | 宮殿の線にそって一歩。斜めの線も使えます。宮殿から出られません。 |
| 士（小さい駒） | 将と同じく、宮殿の線にそって一歩。宮殿の中だけ。 |
| 象 | まっすぐ一点、そこから外側へ斜めに二点。途中の点に駒があると動けません。 |
| 馬 | まっすぐ一点、そこから外側へ斜めに一点。最初の点に駒があると動けません。 |
| 車 | 線にそってどこまでも。宮殿の中では斜めの線にそっても進めます。 |
| 包 | 動くときも取るときも、**ちょうど一つ**の駒を飛び越えなければなりません。ほかの包は飛び越えられず、取ることもできません。宮殿の中では斜めにも飛び越えられます。 |
| 兵 卒 / 兵（小さい駒） | 前か横に一歩。後ろには戻れません。相手の宮殿の中では線にそって斜め前にも進めます。 |

「駒」ボタンをタップすると、いつでも一覧を大きな絵で見られます。

## 特別なルール

- **王手**と**詰み**はチェスと同じです。詰ませれば勝ちです。
- **パス**：指す代わりに「パス」を押せます。ただし王手をかけられているときはできません。動ける駒がないときはパスします。
- **将の向かい合い**（ビッチャン）：二つの将が間に何もない同じ線に並ぶと、このアプリでは**引き分け**になります（伝統ルールを簡単にしたものです）。
- 二人が続けてパスしたときも引き分けです。

## アプリでの遊び方

1. 自分の青い駒をタップすると、行ける場所が緑の点で表示されます。
2. 緑の点をタップすると動きます。取った駒は盤の上と下に表示されます。
3. 「一手戻す」はあなたの最後の手とコンピューターの応手を取り消し、「ヒント」は良い手を示します。

## レベル

- **かんたん**：一手先だけを見て、よくまちがえます。
- **ふつう**：数手先まで読みます。
- **むずかしい**：1秒以内でできるだけ深く読みます。ほかに手がないときだけパスします。

## 簡単にしたところ

初期配置は両者とも同じ（左から馬・象・象・馬）で、伝統的な馬と象の入れ替えは選べません。終局時の点数計算はありません。同じ局面が**三回**現れたとき、**おたがい60手駒を取らなかった**とき、どちらにも攻める駒が残っていないときは引き分けです。

## コツ

- いちばん強いのは車、その次が包と馬です。
- 包には飛び越える駒が必要です。序盤のうちに「台」を用意しましょう。
- 宮殿の斜めの線を使いましょう。宮殿の角にいる車や包は、反対の角をねらえます。
