# たびの物語

🌐 [English](../../en/games/journey.md) · [Português](../../pt-BR/games/journey.md) · [Español](../../es/games/journey.md) · [Français](../../fr/games/journey.md) · [Italiano](../../it/games/journey.md) · [Deutsch](../../de/games/journey.md) · [Русский](../../ru/games/journey.md) · **日本語** · [中文](../../zh-CN/games/journey.md) · [العربية](../../ar/games/journey.md)

城と騎士の王国で、ブラジルの民話の仲間たちと出会う、ゆっくり遊べるターン制の冒険です。だれもせかしません。敵はあなたの番を待ってくれますし、負けても何も失いません。

## はじめに
**職業** を選んで **名前** を入力します：

| 職業 | とくい |
|---|---|
| 騎士 | 体力が多く、**強打** がある。 |
| 弓使い | すばやい。**矢の雨** で敵みんなを攻撃。 |
| 魔法使い | **炎** と **氷** のまほう。 |
| いやし手 | **光** で仲間をいやす。 |

かじ屋の **ベント** は最初からいっしょです。仲間を **かばう** ことができ、攻撃を引き受けてくれます。森では炎の魔法使い **リア** を助けられます。

## 地図と村
地図の場所をタップするとそこへ行きます。前の場所を終えると次が開きます。勝った戦いはもう一度できるので、強くなれます。宝箱や仲間からポーション、エーテル、ゴールドがもらえます。**村** では **宿屋で休む**（全員の体力とマナが元どおり）、**サシ** にヒントを聞く、敵の強さ（かんたん・ふつう・むずかしい）をいつでも変える、ができます。

## 戦い
上の帯に、次にだれの番かが表示されます。すばやい人が先です。自分の番に選びます：
- **こうげき**、そして相手。
- **まほう**：まほうはマナを使います。
- **ぼうぎょ**：次の番までダメージが半分になり、マナが少しもどります。
- **どうぐ**：ポーションは体力が半分もどり、エーテルはマナがもどります。
- **おすすめ** はよい手を代わりに打ち、**おまかせ** は仲間の番を全部進めます。

敵はそれぞれ、あるまほうに **弱く**（ダメージ1.5倍）、別のまほうに **強い**（半分）です。最初に当てると、大きなマークで弱点がわかります。敵は死にません。にげるか、気をうしなうだけです。

| 敵 | 弱点 | 強い |
|---|---|---|
| みどりスライム | 炎 | 氷 |
| イノシシ | 氷 | 炎 |
| ねむりキノコ | 炎 | 光 |
| はいいろオオカミ | 光 | 氷 |
| 大イノシシ（ボス） | 氷 | 炎 |

全員が倒れても、宿屋で元気に目をさまし、持ち物もそのままです。

## レベル
戦いで経験とゴールドがもらえます。レベルが上がるたびに、体力・こうげき・ぼうぎょ・マナ・すばやさのアップか、新しいまほうを選びます。
