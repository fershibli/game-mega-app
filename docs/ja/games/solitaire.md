# ソリティア

**目的：** クロンダイクです。すべてのカードを上の4つの山に、マークごとに A から K の順に集めます。

**遊び方：** **カードをタップする** だけです。カードはいちばんよい場所に動きます。上の山に置ければそこへ、だめなら列の上へ（赤と黒を交互に、数字は1つ小さく）、それもだめなら空いた列へ（K だけ）動きます。動かせないときは赤く光ります。列の中の表向きのカードをタップすると、その上に重なっているカードもいっしょに動きます。**山札**（右上、左利きモードでは左上）をタップするとカードがめくれます。山札がなくなったら、もう一度タップすると、めくったカードを裏返して山札に戻せます。**ヒント** は役に立つ手をふちどりで示します。すべてのカードが表向きになると **自動で仕上げる** が表示され、残りを自動で進めます。

| むずかしさ | めくる枚数 | 山札をめくれる回数 |
|---|---|---|
| かんたん | 1枚 | 何回でも |
| ふつう | 3枚 | 何回でも |
| むずかしい | 3枚 | 3回 |
