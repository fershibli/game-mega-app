# カラードロップ

2つ組の丸いしずくが、細い井戸（6列×12段）をゆっくり落ちてきます。同じ色をそろえましょう。**同じ色のしずくが3つ以上**（上下左右で）つながると消え、上のしずくが落ちてきます。その落下で別のかたまりも消えると**連鎖**になり、得点が増えます。

どの色にも記号（点、四角、三角、ひし形、十字）が付いているので、色合いだけで見分ける必要はありません。

## 遊び方
- 準備ができたら**スタート**を押します。それまでは何も動きません。
- 大きなボタンで、しずくを**左**・**右**に動かしたり、**回転**させたり、一番下まで**落とし**たりできます。井戸の上で指をすべらせても操作できます（横で移動、下で落とす、タップで回転）。
- **一時停止**ですべて止まります。設定を開いたりアプリを離れたりしたときも自動で止まり、**続ける**を押すまで待ちます。
- 真ん中の列の上（新しいしずくが入る所）がいっぱいになると終わりです。得点と、そのレベルの最高得点が表示されます。

## 得点
- 消えたしずく1つにつき10点。
- 連鎖では、消えるたびに前の2倍になります（最大16倍）。

## レベル
- **かんたん：** 3色、とてもゆっくり落ち、次のしずくが見えます。ボタンに指を置いている間は落ちてきません。
- **ふつう：** 4色、ゆっくり落ちます。
- **むずかしい：** 5色、少しだけ速く落ちます（それでも、のんびりです）。

## コツ
- 真ん中の列は低く保ち、新しいしずくがいつも入れるようにしましょう。
- 同じ色を2つ重ねて3つめを近くに置いておくと、あとで落としたときに連鎖が始まります。
