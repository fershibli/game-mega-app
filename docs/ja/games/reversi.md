# リバーシ

**目的：** 盤がうまったときに、コンピューターより多くの石を持つことです。あなたは黒い石で、先に打ちます。

置いた石と、もとからある自分の石とで、コンピューターの石を1つ以上まっすぐはさむように置きます。はさまれた石は、あなたの色に変わります。置ける場所は小さな点で表示され、コンピューターが最後に打った場所には赤い点がつきます。置ける場所がないときはパスになります（アプリがお知らせします）。

**ヒント** はよい手に印をつけます。**一手戻す** で、あなたの最後の手を取り消せます。コンピューターの強さ：1手先を読み、ときどきまちがえる／3手先まで読む／6手先まで読み、最後の12手は完ぺきに打つ。
