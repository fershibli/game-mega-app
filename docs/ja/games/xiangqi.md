# シャンチー（中国象棋）

🌐 [English](../../en/games/xiangqi.md) · [Português](../../pt-BR/games/xiangqi.md) · [Español](../../es/games/xiangqi.md) · [Français](../../fr/games/xiangqi.md) · [Italiano](../../it/games/xiangqi.md) · [Deutsch](../../de/games/xiangqi.md) · [Русский](../../ru/games/xiangqi.md) · **日本語** · [中文](../../zh-CN/games/xiangqi.md) · [العربية](../../ar/games/xiangqi.md)

シャンチーは中国やベトナムでいちばんよく遊ばれているボードゲームです。川をはさんで二つの軍が向かい合い、相手の**将**を追いつめたほうが勝ちです。

## 盤

- 横9本・縦10本の線があり、駒はマスの中ではなく**線の交点**に置きます。
- 盤のまん中を**川**が横切っています。川を渡ると動きが変わる駒があります。
- それぞれの側に**九宮（宮殿）**があります。X印のある3×3の交点です。将と二つの士はここから出られません。
- あなたは**赤**で、下側から先に指します。コンピューターは黒です。

## 駒と印

駒には伝統の文字が書かれ、そのまわりに動き方を表す小さな印があります。文字が読めなくても遊べます。

- **点** ＝ その方向に一歩、**点が二つ** ＝ 二歩
- **矢印** ＝ その方向にどこまでも
- **横線つきの矢印** ＝ 駒を一つ飛び越えて取る
- **白抜きの点** ＝ 川を渡ってからできる動き

| 駒 | 印 | 動き方 |
|---|---|---|
| 将 帥 / 將 | まっすぐの点4つ | 線にそって一歩。九宮の中だけ。 |
| 士 仕 / 士 | 斜めの点4つ | 斜めに一歩。九宮の中だけ。 |
| 象 相 / 象 | 斜めの点のペア4組 | 斜めにちょうど二点。川は渡れず、間の点（象の目）に駒があると動けません。 |
| 馬 | 点8つ | まっすぐ一点、そこから外側へ斜めに一点。その方向の隣の点に駒があると進めません（馬の足止め）。 |
| 車 | 矢印4本 | 線にそってどこまでも。いちばん強い駒です。 |
| 砲 炮 / 砲 | 横線つきの矢印4本 | 動きは車と同じですが、**取る**ときはちょうど一つの駒（どちらの駒でも）を飛び越えます。 |
| 兵 兵 / 卒 | 前に点1つ、横に白抜きの点2つ | 前に一歩。川を渡ると横にも一歩。後ろには戻れません。 |

「駒」ボタンをタップすると、いつでもこの一覧を大きな絵で見られます。

## 特別なルール

- **将どうしは**、間に何もない同じ線で**向かい合ってはいけません**。そうなる手は指せません。
- **王手**：あなたの将がねらわれています。王手をはずさなければなりません。
- **詰み**で勝ちです。シャンチーでは、王手でなくても**指せる手がまったくない**と**負け**になります。

## アプリでの遊び方

1. 自分の赤い駒をタップすると、行ける場所が緑の点で表示されます（相手の駒のまわりの緑の輪は、その駒を取れるという意味です）。上の表示に駒の名前と動き方が出ます。
2. 緑の点をタップすると動きます。
3. 「一手戻す」はあなたの最後の手とコンピューターの応手を取り消します。「ヒント」は良い手を矢印で示します。
4. それぞれが取った駒は盤の上と下に表示されます。

## レベル

- **かんたん**：一手先だけを見て、よくまちがえます。練習にぴったりです。
- **ふつう**：数手先まで読み、駒をただで取られるようなことはしません。
- **むずかしい**：1秒以内でできるだけ深く読みます。

## 簡単にしたところ

正式なルールでは長将（同じ王手のくり返し）や長捉が禁止ですが、ここではくり返しは単に**引き分け**です。同じ局面が**三回**現れたとき、**おたがい60手駒を取らなかった**とき、どちらにも攻められる駒（馬・車・砲・兵）が残っていないときも引き分けです。

## コツ

- 車は早めに使いましょう。馬およそ二つ分の価値があります。
- 砲は取るのに「台」になる駒が必要です。駒の多い序盤にいちばん強い駒です。
- 士と象は将の近くに置いて、護衛にしましょう。
