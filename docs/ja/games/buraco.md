# ブラコ

🌐 [English](../../en/games/buraco.md) · [Português](../../pt-BR/games/buraco.md) · [Español](../../es/games/buraco.md) · [Français](../../fr/games/buraco.md) · [Italiano](../../it/games/buraco.md) · [Deutsch](../../de/games/buraco.md) · [Русский](../../ru/games/buraco.md) · **日本語** · [中文](../../zh-CN/games/buraco.md) · [العربية](../../ar/games/buraco.md)

ブラコは、2組のトランプで「組（同じマークの連番）」と「カナスタ」を作る、ブラジルで人気のラミー系ゲームです。Mili Games では **2人**（あなた対コンピューター）か、**4人のペア戦**（向かい合わせに座るあなたとコンピューターのパートナー対コンピューター2人）で遊べます。毎回はじめに **何人で遊びますか？** と聞かれ、前回の選択を覚えています。**1台のスマホを順番に回して** 人どうしで遊ぶこともできます。

## カード
- 52枚のトランプ2組（104枚）、ジョーカーなし。**2はすべてワイルド**（「クリンガ」）。
- 全員に **11枚** ずつ配ります。11枚の山がさらに2つ、**モルト** として脇に置かれ（各チームに1つ）、1枚が捨て札の始まりです。

## あなたの番
1. 山から1枚 **引く** か、**捨て札をすべて取ります**。
2. 必要なら **組を出します**：**同じマークの連続した3枚以上**（5♥ 6♥ 7♥）を選んで **新しい組**。Aは下（A-2-3）にも上（Q-K-A）にも使えます。ワイルドの2は1つの組に **1枚** だけ。本来の位置にある同じマークの2（A-2-3♥）は普通の札です。
3. 必要なら自分のチームの組に **札を付けます**：選んでから組をタップ。
4. 1枚 **捨てます**。**一手戻す** で、引いたあとに出した札をすべて戻せます。

**カナスタ：** 7枚以上の組。**クリーン**（ワイルドなし、金の枠）は200点、**ダーティ**（ワイルドあり、銀の枠）は100点。

**モルト：** 手札が初めてなくなった人は、自分のチームのモルトを取って続けます（捨てたときになくなったら、次の番から使います）。

**上がり（バテール）：** 手札を完全になくせるのは、チームがすでにモルトを取っていて（または残っていない）、**かつ** **クリーンのカナスタ** が1つ以上あるときだけ。山がなくなってもゲームは終わります。

## 得点
| 項目 | 点 |
|---|---|
| A | 15 |
| 2、8〜K | 10 |
| 3〜7 | 5 |
| クリーンのカナスタ | +200 |
| ダーティのカナスタ | +100 |
| 上がり | +100 |
| 手に残った札 | その点数を引く |
| モルトを取らなかった | −100 |

## 4人のペア戦
- **席：** あなたは下、**パートナー** は向かい、相手は **左** と **右**。席ごとに色と記号があります（● あなた、▲ 右、■ パートナー、◆ 左）。番の人は明るい枠で囲まれ、各席の手札の枚数も表示されます。
- **順番：** ブラジルの習慣どおり反時計回り。あなたの次は **右** の人、次にパートナー、その次に左の人です。
- **チームで1つの場：** あなたとパートナーは **同じ組**（「味方の組」）に出したり付けたりします。相手チームも同様です。モルトは **チームに1つ**：先に手札がなくなったほうが取ります。
- **チームの得点：** 上のバーに、各チームが場に出している点数が出ます。終了時は組とカナスタの点、どちらかが上がれば +100、**2人分** の残り札を引き、モルトを取らなければ −100。
- **コンピューターのパートナー** は共有の組に札を付け、「むずかしい」ではクリーンのカナスタを守り、次の相手が使えそうな札は捨てません。

## 1台のスマホを順番に
レベルの画面で **交代で遊ぶ（このスマホで）** を選び、テーブルの人数（2か4）を選びます。全員が人です（2人、または4人のペア：プレイヤー1と3対2と4）。捨てるたびにカバーが札を隠し、次の人（色と記号つき）にスマホを渡すよう表示します。次の人が大きなボタン（「準備ができました。私の番です」）をタップすると自分の手札が見えます。

## レベル
- **かんたん：** 気楽に打ち、捨て札はめったに取らず、ほぼ適当に捨てます。
- **ふつう：** 役に立つときは捨て札を取り、ワイルドを大事にし、相手チームの組に付く札は捨てません。
- **むずかしい：** 捨て札全体も評価し、クリーンのカナスタを守り、相手チームが取った札を覚えています。

コンピューターがあなたの札を見ることはありません。

## コツ
- 上がるにはクリーンのカナスタが鍵。2を早く使いすぎないように。
- 相手の組を伸ばす札を捨てる前に、捨て札をよく見ましょう。
- ペアでは新しい組を作るより共有の組に付けるほうが、早くカナスタになります。
