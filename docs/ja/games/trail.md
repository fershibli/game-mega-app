# 人生の道

🌐 [English](../../en/games/trail.md) · [Português](../../pt-BR/games/trail.md) · [Español](../../es/games/trail.md) · [Français](../../fr/games/trail.md) · [Italiano](../../it/games/trail.md) · [Deutsch](../../de/games/trail.md) · [Русский](../../ru/games/trail.md) · **日本語** · [中文](../../zh-CN/games/trail.md) · [العربية](../../ar/games/trail.md)

2〜4人で遊ぶ、のんびりしたすごろくです。さいころをふって、盤の下の子どものころから、上のおだやかな日々まで、人生をひとめぐりします。道の途中で **ハート** を集め、全員がゴールしたときにハートがいちばん多い人の勝ちです。ふりだしにもどることはなく、悪いことも起きません。競争ではなく、お散歩です。

コンピューター（ほかのこまを動かします）と遊ぶか、**このスマホを順番に** 回して遊びます。何人で遊ぶかを最初に聞かれます。

## 盤
人生の6つの時期が1段ずつ並んでいます：**子どものころ**・**青春**・**仕事**・**家族**・**旅**・**おだやかな日々**。道は旗から小さな家まで、じぐざぐにのぼっていきます。

| マス | 起きること |
|---|---|
| ♥ ハート | ハート1つ。 |
| 📖 本 | その時期の物語。読んで **つづける** をタップします。たいていはハート1〜3つ、いくつかは1〜2マス動きます。 |
| 道しるべ | 分かれ道：**立ち止まる** とハート2つ、**先へ進む** と3マス進みます。 |
| ふつう | 何もありません。景色を楽しみましょう。 |

## ゴール
家にいちばんに着いた人はハート **5つ**、2番目は **3つ**、3番目は **2つ**、4番目は **1つ** もらえます。ぴったりの目でなくてもゴールできます。全員のこまが着いたら終わりで、最後にハートの数が出ます。

## コツ
- 分かれ道で立ち止まるとハート2つ。1つ早く着くと最大2つ多くもらえます。終わり近くで後ろの人が近いときは、先へ進むのも手です。
- **かんたん** ではコンピューターは分かれ道をでたらめに選び、**ふつう** と **むずかしい** では、ゴールのボーナスが増えるときだけ急ぎます。
