# 言葉あて

🌐 [English](../../en/games/guessword.md) · [Português](../../pt-BR/games/guessword.md) · [Español](../../es/games/guessword.md) · [Français](../../fr/games/guessword.md) · [Italiano](../../it/games/guessword.md) · [Deutsch](../../de/games/guessword.md) · [Русский](../../ru/games/guessword.md) · **日本語** · [中文](../../zh-CN/games/guessword.md) · [العربية](../../ar/games/guessword.md)

かくれた言葉を1文字ずつ当てるゲームです。花を大切にしましょう。言葉にない文字を選ぶたびに、花びらが1枚落ちます。最後の花びらが落ちる前に言葉を見つけましょう！

## 遊び方

- 言葉のマスは空いた四角で表示され、その下にヒントがあります。
- 下のカタカナから1文字をタップします。言葉にある文字なら、その文字が入る**すべて**のマスに一度に入り、ボタンに ✓ がつきます。
- 言葉にない文字なら、花びらが1枚ゆっくり草の上に落ち、ボタンに — がつきます。言葉になかった文字はヒントの下に並びます。
- 言葉が見つかると、花が大きく開き、お日さまが出てきます。
- 最後の花びらが落ちたら、答えがそっと表示され、次の言葉のために新しい花が植えられます。
- **ヒント**は、かくれているヒントを表示し、そのあとは最初の空いたマスに文字を入れます。ヒントで花びらは落ちません。
- 1回に5つの言葉があります。最後に、当てた数と残った花びらの数がわかります。

答えはカタカナで、小さい「ッ」「ャ」なども大きく書きます。

## レベル

- **やさしい**：花びら8枚、ヒントと1文字が最初から表示されます。
- **ふつう**：花びら6枚とヒント。
- **むずかしい**：花びら5枚、長めの言葉。ヒントは**ヒント**をタップしてから。

## コツ

- まずヒントをよく読みましょう。
- 「ン」や「ー」など、よく使われる文字から試すと見つけやすくなります。
