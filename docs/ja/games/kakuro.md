# たし算クロス

🌐 [English](../../en/games/kakuro.md) · [Português](../../pt-BR/games/kakuro.md) · [Español](../../es/games/kakuro.md) · [Français](../../fr/games/kakuro.md) · [Italiano](../../it/games/kakuro.md) · [Deutsch](../../de/games/kakuro.md) · [Русский](../../ru/games/kakuro.md) · **日本語** · [中文](../../zh-CN/games/kakuro.md) · [العربية](../../ar/games/kakuro.md)

数字のクロスワードです。白いマスに1〜9の数字を入れます。たて・よこに続く白いマスの合計は、その前の黒いマスの数字になります。黒いマスの右上の数字は右へ続くマスの合計、左下の数字は下へ続くマスの合計です。続いたマスの中で同じ数字は使えません。

## 遊び方

- 白いマスをタッチしてから数字をえらびます。同じ数字をもう一度おすか、消しゴムで消せます。
- **メモ**をオンにすると、数字がマスの中の小さなメモになります。
- えらんだマスを通る列に色がつき、その合計が目立ちます。
- **ヒント**は、まずえらんだマスの合計になる数字の組み合わせを表示します（→ よこ、↓ たて）。もう一度おすと、そのマスに数字が入ります。
- **一手戻す**で直前の変更を取り消します。二本指で拡大できます。

## レベル

- **かんたん**：枠の中が5×5、続くマスは4つまで。まちがいは赤で表示されます。
- **ふつう**：7×7、5つまで。まちがいは赤で表示されます。
- **むずかしい**：9×9、5つまで。まちがった数字は表示されませんが、同じ数字の重なりと合計のまちがいは表示されます。

問題はアプリが作り、答えは必ず1つです。当てずっぽうなしに、考えるだけで解けます。

## コツ

- 組み合わせが1通りしかない合計があります。2マスで3は1+2、4は1+3、16は7+9、17は8+9。3マスで6は1+2+3、24は7+8+9。
- 2つの列が交わるマスの数字は、両方に合わなければなりません。
