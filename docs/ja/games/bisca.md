# ビスカ

## カード
- 40枚：ふつうのトランプから 8、9、10 をぬいたものです。1人に **3枚** 配ります。
- どのマークも、強い順に **A、7、K、J、Q、6、5、4、3、2**。点数：**A 11点、7 10点、K 4点、J 3点、Q 2点**、全部で **120点**。
- 配ったあと1枚を表にして **切り札** にし、山の下に置きます（左上）。この札は最後に引かれます。切り札のカードには小さな星がついています。

## 遊び方
- 配った人の次の人から始めます。いちばん強い切り札が取ります。切り札がなければ、最初に出たマークのいちばん強いカードが取ります。
- 1回ごとに全員が山から **1枚引きます**。取った人から引き、取った人が次の回の最初に出します。
- **山にカードがあるあいだは、どのカードを出してもかまいません。** 同じマークを出す必要はありません。
- **山がなくなったら、出せるときは同じマークを出します**（勝つカードや切り札を出す必要はありません）。出せないカードは灰色です。
- カードをタップすると持ち上がり、もう一度タップするか **カードを出す** を押すと出せます。**ヒント**はカードを選んでくれます。出したカードはもどせません。相手がもう見ているからです。

## 点の数え方
- **61点以上** で **1ゲーム**、**91点以上** で **2ゲーム**。60対60は引き分けです。
- 先に **4ゲーム** 取った側の勝ちです。

## レベル
コンピューターは伏せたカードも、山の順番も見ません。
- **やさしい：** よく適当にカードを出します。
- **ふつう：** 何もない回には小さいカードを出し、A と 7 はできるだけ安く取り、あなたがただで切れる A は出しません。ペアのときはパートナーを助けます。
- **むずかしい：** 見えないカードの順番をたくさん思いえがき、各カードを最後まで試して、いちばん点が取れるカードを選びます。

## コツ
- 小さい切り札は、相手の A や 7 を取るために取っておきましょう。
- 山があるあいだは点のない小さいカードから出し、最後の回では、まだ出ていない A と 7 を数えましょう。

## 地方のルール
ビスカは地域によってちがいます。7枚や9枚で遊んだり、切り札の 2 を表の札と取りかえたり、最後まで同じマークを出さなくてよかったりします。Mili Games では3枚で、取りかえはなく、山がなくなったら同じマークを出します。
