# チェス

🌐 [English](../../en/games/chess.md) · [Português](../../pt-BR/games/chess.md) · [Español](../../es/games/chess.md) · [Français](../../fr/games/chess.md) · [Italiano](../../it/games/chess.md) · [Deutsch](../../de/games/chess.md) · [Русский](../../ru/games/chess.md) · **日本語** · [中文](../../zh-CN/games/chess.md) · [العربية](../../ar/games/chess.md)

戦略ゲームの定番です。あなたは画面の下側の白、コンピューターは黒を持ちます。コンピューターのキングを**チェックメイト**(逃げ場のないように攻めること)すれば勝ちです。

## コンピューターと対局

- 自分の駒をタップすると、動けるマスに点(取れるマスには輪)が表示されます。そのどれかをタップします。
- 最後の手は色がつき、チェックされたキングは赤く囲まれます。
- ルールはすべてそろっています: キャスリング(キングを2マス動かす)、アンパッサン、プロモーション(相手の端に着いたポーンはクイーン、ルーク、ビショップ、ナイトになります。大きなボタンで、最初がクイーン)、チェック、チェックメイト、ステイルメイト。
- ステイルメイト、どちらもメイトできる駒が足りないとき、双方50手のあいだ駒を取らずポーンも動かさなかったとき、同じ局面が3回現れたときは引き分けです。
- **一手戻す**で自分の手とコンピューターの返し手を取り消せます。**ヒント**はよい手を教えてくれます。

## 名局

歴史に残る7つの名局を、一手ずつ再現できます。大きな**最初**・**戻る**・**次へ**・**最後**のボタンと、指し手の一覧があります(手をタップするとその場面に移ります)。対局者、場所、年、そして有名な理由も表示されます:

- 不滅の一局: アンデルセン対キーゼリツキー、ロンドン 1851年
- 常緑の一局: アンデルセン対デュフレーヌ、ベルリン 1852年
- オペラ座の一局: モーフィー対ブラウンシュヴァイク公カールとイスアール伯爵、パリ 1858年
- シュタイニッツ対バルデレーベン、ヘイスティングズ 1895年
- レティ対タルタコワ、ウィーン 1910年
- 世紀の一局: D・バーン対フィッシャー、ニューヨーク 1956年
- カスパロフ対トパロフ、ウェイク・アーン・ゼー 1999年

ここではレベルは関係ありません。

## レベル

- **かんたん**: 1手先まで読み、ときどき弱い手を選びます。気軽に遊ぶ人でも勝てます。
- **ふつう**: 3手先くらいまで読みます。
- **むずかしい**: 4〜5手先まで読み、うっかり駒を取られるようなことはしません。

## コツ

- ナイトとビショップを早めに出し、キャスリングでキングを安全にしましょう。
- 毎回、コンピューターが何をねらっているか考えてから指しましょう。
- 指し手は駒の絵で書かれます: ♘f3 は「ナイトをf3へ」、x は駒を取る手、+ はチェック、# はチェックメイトです。
