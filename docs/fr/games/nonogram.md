# Nonogramme

🌐 [English](../../en/games/nonogram.md) · [Português](../../pt-BR/games/nonogram.md) · [Español](../../es/games/nonogram.md) · **Français** · [Italiano](../../it/games/nonogram.md) · [Deutsch](../../de/games/nonogram.md) · [Русский](../../ru/games/nonogram.md) · [日本語](../../ja/games/nonogram.md) · [中文](../../zh-CN/games/nonogram.md) · [العربية](../../ar/games/nonogram.md)

Peindre avec des nombres. Les nombres à côté de chaque ligne et au-dessus de chaque colonne donnent la longueur des blocs peints de cette ligne, dans l’ordre ; entre deux blocs il y a au moins une case vide. Peignez les bonnes cases et une image apparaît : à la fin, elle s’affiche en couleur avec son nom.

## Comment jouer

- Touchez une case pour la peindre ; touchez-la encore pour l’effacer.
- Appuyez longuement sur une case pour la marquer d’un ✕ (une case qui reste vide). Avec **Marquer** activé, un toucher met un ✕ et un appui long peint.
- Glissez le long d’une ligne ou d’une colonne pour peindre (ou marquer) plusieurs cases d’un coup.
- Les nombres d’une ligne pâlissent quand ses cases peintes y correspondent.
- **Annuler** reprend le dernier changement. **Indice** corrige d’abord une erreur ; sinon il peint une case qu’une ligne décide déjà.
- Pincez pour zoomer sur les grandes grilles.

## Niveaux

- **Facile** : 5×5. Les erreurs sont en rouge.
- **Moyen** : 10×10. Les erreurs sont en rouge.
- **Difficile** : 15×15. Les erreurs ne sont pas montrées.

Chaque grille se résout ligne par ligne, sans deviner. Les images (plus de 20 par taille : animaux, fleurs, une maison, un bateau, une théière...) ont été dessinées pour l’application ; si aucune ne convient, un motif au hasard est utilisé.

## Astuces

- Commencez par les grands nombres : un bloc de 8 dans une ligne de 10 couvre toujours les 6 cases du milieu.
- Une ligne avec 0 est entièrement vide : marquez-la de ✕.
- Marquez les cases vides d’un ✕ : elles aident les lignes qui les croisent.
