# Tangram

🌐 [English](../../en/games/tangram.md) · [Português](../../pt-BR/games/tangram.md) · [Español](../../es/games/tangram.md) · **Français** · [Italiano](../../it/games/tangram.md) · [Deutsch](../../de/games/tangram.md) · [Русский](../../ru/games/tangram.md) · [日本語](../../ja/games/tangram.md) · [中文](../../zh-CN/games/tangram.md) · [العربية](../../ar/games/tangram.md)

Sept pièces plates (deux grands triangles, un moyen, deux petits, un carré et un parallélogramme) forment une figure. Remplis la figure avec les sept pièces, sans les superposer.

## Comment jouer
- Fais glisser une pièce pour la déplacer et touche-la pour la tourner.
- **Retourner** retourne le parallélogramme.
- Les pièces se placent toutes seules quand elles sont proches. **Indice** place une pièce ; **Recommencer** les retire toutes.

## Niveaux
- **Facile :** le contour de chaque pièce est dessiné dans la figure.
- **Moyen :** trois pièces sont dessinées.
- **Difficile :** seulement la figure.

## Astuces
- Commence par les deux grands triangles : ils remplissent presque toute la figure.
