# Cryptogramme

🌐 [English](../../en/games/cryptogram.md) · [Português](../../pt-BR/games/cryptogram.md) · [Español](../../es/games/cryptogram.md) · **Français** · [Italiano](../../it/games/cryptogram.md) · [Deutsch](../../de/games/cryptogram.md) · [Русский](../../ru/games/cryptogram.md) · [日本語](../../ja/games/cryptogram.md) · [中文](../../zh-CN/games/cryptogram.md) · [العربية](../../ar/games/cryptogram.md)

Un proverbe connu est écrit en code : chaque lettre a été remplacée par un autre symbole. Trouve quelle lettre se cache derrière chaque symbole et le proverbe apparaît.

## Comment jouer

- Chaque case montre son symbole en petit sous un trait. En **Facile**, les symboles sont des nombres (1, 2, 3…) ; aux autres niveaux, ce sont d’autres lettres. Une lettre ne se cache jamais derrière elle-même.
- Touche une case : toutes les cases avec le même symbole s’allument. Touche ensuite la lettre qu’elle cache selon toi : elle s’écrit dans toutes ces cases à la fois.
- Si tu places une lettre déjà mise sur un autre symbole, elle se déplace ici. Le bouton ⌫ efface la lettre du symbole choisi.
- Les lettres sur fond vert ont été révélées et sont toujours justes.
- **Indice** écrit la bonne lettre sur le symbole choisi (ou sur le premier qui n’est pas encore juste).
- Quand toutes les lettres sont justes, le proverbe entier s’affiche.

Tous les proverbes sont traditionnels. Les accents ne sont pas écrits (É devient E, Ç devient C, Œ devient OE).

Le cryptogramme se joue en français, anglais, portugais, espagnol, italien, allemand, russe et arabe. Le japonais et le chinois ne s’écrivent pas avec un petit alphabet dont on pourrait échanger les lettres : dans ces langues, le jeu demande d’abord dans laquelle de ces langues jouer.

## Niveaux

- **Facile** : des nombres au lieu des lettres, et trois lettres déjà révélées.
- **Moyen** : des lettres, une révélée.
- **Difficile** : des lettres, aucune révélée.

## Conseils

- Commence par les mots courts : un mot d’une lettre est souvent A ou Y, et les petits mots LE, LA, LES, DE, ET reviennent souvent.
- Un symbole très fréquent est sans doute une voyelle (E, A) ou une lettre courante comme S ou T.
- Pense aux proverbes connus : avec quelques lettres en place, la suite vient souvent toute seule.
