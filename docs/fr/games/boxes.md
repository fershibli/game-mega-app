# Pousse-caisses

🌐 [English](../../en/games/boxes.md) · [Português](../../pt-BR/games/boxes.md) · [Español](../../es/games/boxes.md) · **Français** · [Italiano](../../it/games/boxes.md) · [Deutsch](../../de/games/boxes.md) · [Русский](../../ru/games/boxes.md) · [日本語](../../ja/games/boxes.md) · [中文](../../zh-CN/games/boxes.md) · [العربية](../../ar/games/boxes.md)

Promène le petit ami tout rond dans la pièce et pousse chaque caisse sur un rond.

## Comment jouer
- Glisse le doigt, utilise les flèches ou touche une case pour y aller.
- Avance contre une caisse pour la pousser d’une case. Les caisses se poussent, jamais ne se tirent, et une à la fois.
- **Annuler** autant que tu veux ; **Recommencer** remet la pièce au début ; **Indice** montre le pas suivant.
- Si une caisse est coincée là où elle ne peut plus atteindre un rond, le jeu le dit : touche Annuler pour la libérer.

## Niveaux
- **Facile :** 2 caisses dans une petite pièce.
- **Moyen :** 3 caisses.
- **Difficile :** 4 caisses dans une pièce plus grande, avec plus de murs.

## Astuces
- Réfléchis avant de pousser une caisse contre un mur : elle ne peut plus que glisser le long du mur.
- Une caisse dans un coin n’en sort plus : évite les coins sans rond.
