# Pyramide

🌐 [English](../../en/games/pyramid.md) · [Português](../../pt-BR/games/pyramid.md) · [Español](../../es/games/pyramid.md) · **Français** · [Italiano](../../it/games/pyramid.md) · [Deutsch](../../de/games/pyramid.md) · [Русский](../../ru/games/pyramid.md) · [日本語](../../ja/games/pyramid.md) · [中文](../../zh-CN/games/pyramid.md) · [العربية](../../ar/games/pyramid.md)

Une réussite d’additions. 28 cartes forment une pyramide de sept rangées ; les 24 autres sont le talon. Retirez **deux cartes dont la somme fait 13**. Videz toute la pyramide pour gagner.

## Comment jouer

- Valeurs : As = 1, les chiffres tels quels, Valet (V) = 11, Dame (D) = 12, Roi (R) = 13. Ainsi Dame + As, Valet + 2, 10 + 3, 9 + 4, 8 + 5 et 7 + 6 font 13, et le **Roi part seul**. Les valeurs sont rappelées en haut de l’écran.
- Seules les cartes **dégagées** peuvent être prises : une carte est libre quand aucune carte de la rangée du dessous n’est posée dessus. Les cartes couvertes sont un peu plus sombres.
- Touchez une carte, puis une autre : si leur somme fait 13, elles partent toutes les deux. Le jeu vous dit ce que vaut la première carte et ce qu’il lui faut. Touchez un Roi une fois pour le retirer.
- Touchez le **talon** (du côté de votre pouce) pour retourner une carte ; elle peut faire une paire avec une carte de la pyramide. Quand le talon est vide, touchez-le encore pour le reprendre, si votre niveau le permet encore.
- **Annuler** revient en arrière. **Indice** montre une paire (ou vous dit de retourner le talon). Quand plus rien ne peut être retiré, le jeu vous le dit : vous pouvez annuler, abandonner ou continuer à chercher.

## Niveaux

Chaque donne peut être vidée si l’on peut parcourir le talon autant de fois qu’on veut (l’application le vérifie avant que vous jouiez).

- **Facile** : parcourez le talon autant de fois que vous voulez.
- **Moyen** : trois tours de talon.
- **Difficile** : un seul tour de talon.

## Conseils

- Préférez les paires qui libèrent des cartes de la pyramide aux paires avec le talon.
- Quand vous pouvez choisir entre deux cartes égales, prenez celle qui en dégage le plus.
- Les Rois sont gratuits : retirez-les dès qu’ils sont dégagés.
- En Moyen et Difficile, regardez toute la pyramide avant de retourner la carte suivante : chaque tour compte.
