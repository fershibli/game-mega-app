# Serpent

Un serpent lent et sympathique avance sur une grille. Guidez-le vers les fruits (pommes, cerises, fraises et poires) : chaque fruit l’allonge d’une case. Rien ne presse : le serpent n’avance que pendant la partie, et vous pouvez faire une pause quand vous voulez.

## Comment jouer
- Utilisez les **quatre grandes flèches** (ou glissez le doigt sur le plateau) pour choisir la direction. Toucher une flèche lance aussi la partie.
- **Pause** arrête le serpent. Le jeu se met aussi en pause tout seul quand vous ouvrez les réglages ou quittez l’application ; touchez **Reprendre** pour continuer.
- La longueur et votre record pour ce niveau s’affichent. Le record est gardé même si vous jouez à d’autres jeux.

## Niveaux
- **Facile :** très lent. Le serpent traverse les bords et revient de l’autre côté, et s’il se touche il perd seulement le bout de sa queue ; la partie ne finit jamais.
- **Moyen :** lent. Il traverse toujours les bords, mais se toucher termine la partie.
- **Difficile :** un peu plus rapide, et les bords sont des murs : toucher un mur ou soi-même termine la partie.

## Conseils
- Prévoyez vos virages à l’avance : le serpent retient jusqu’à deux appuis sur les flèches.
- Longer les bords laisse le centre libre pour son long corps.
