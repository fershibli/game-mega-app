# Cellules libres

🌐 [English](../../en/games/freecell.md) · [Português](../../pt-BR/games/freecell.md) · [Español](../../es/games/freecell.md) · **Français** · [Italiano](../../it/games/freecell.md) · [Deutsch](../../de/games/freecell.md) · [Русский](../../ru/games/freecell.md) · [日本語](../../ja/games/freecell.md) · [中文](../../zh-CN/games/freecell.md) · [العربية](../../ar/games/freecell.md)

Une réussite où **toutes les cartes sont visibles** dès le départ : tout est question de réflexion. Montez quatre piles **de l’As au Roi, une par couleur**. Presque toutes les donnes peuvent être gagnées, et dans cette application, toutes le peuvent.

## Comment jouer

- Les 52 cartes sont distribuées sur huit colonnes. Au-dessus se trouvent les **quatre cellules libres** (du côté de votre pouce) et les **quatre piles finales**, une par couleur.
- Sur les colonnes, une carte se pose sur une carte **d’un rang plus haut et de l’autre teinte** (un 6 rouge sur un 7 noir). N’importe quelle carte peut aller sur une colonne vide.
- Chaque cellule libre garde **une carte**, pour la mettre de côté un moment.
- Touchez une carte : elle va à la meilleure place (d’abord sur sa pile, puis sur une autre colonne, dans une cellule libre et enfin sur une colonne vide). Touchez-la encore pour essayer la place suivante.
- Vous pouvez déplacer plusieurs cartes qui se suivent d’un coup s’il y a la place de les porter : (cellules libres + 1), doublé pour chaque colonne vide. Sinon, le jeu vous dit combien de cartes vous pouvez déplacer maintenant.
- Quand toutes les colonnes sont en ordre, **Terminer** envoie toutes les cartes sur leurs piles.
- **Annuler** revient en arrière. **Indice** demande à un solveur le prochain coup d’une partie gagnante. Après chaque coup, le jeu vérifie si la donne peut encore être gagnée ; sinon, il vous le dit et vous pouvez annuler, abandonner ou continuer à chercher.

## Niveaux

Chaque donne est vérifiée par un solveur avant que vous la voyiez : on peut toujours gagner.

- **Facile** : des donnes que le solveur gagne avec seulement deux des quatre cellules libres. Avec les quatre, vous avez de la marge.
- **Moyen** : des donnes qui demandent trois cellules libres.
- **Difficile** : des donnes qui demandent les quatre cellules et une bonne préparation.

## Conseils

- Libérez d’abord les As et les 2 : cherchez-les sous les autres cartes.
- Gardez les cellules vides le plus longtemps possible ; quand elles sont toutes pleines, tout se bloque.
- Une colonne vide vaut plus qu’une cellule : elle double le nombre de cartes déplaçables.
- Avant de jouer, pensez quelques coups à l’avance : où ira la carte que vous allez découvrir ?
