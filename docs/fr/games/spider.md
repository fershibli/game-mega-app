# Araignée

🌐 [English](../../en/games/spider.md) · [Português](../../pt-BR/games/spider.md) · [Español](../../es/games/spider.md) · **Français** · [Italiano](../../it/games/spider.md) · [Deutsch](../../de/games/spider.md) · [Русский](../../ru/games/spider.md) · [日本語](../../ja/games/spider.md) · [中文](../../zh-CN/games/spider.md) · [العربية](../../ar/games/spider.md)

Une réussite à deux jeux (104 cartes) sur dix colonnes. Formez des suites **du Roi à l’As dans une même couleur** : dès qu’une suite est complète, elle quitte la table toute seule. Terminez les huit suites pour gagner.

## Comment jouer

- 54 cartes sont distribuées : six dans chacune des quatre premières colonnes, cinq dans les autres, seule la dernière carte de chaque colonne est visible.
- Vous pouvez poser une carte sur n’importe quelle carte **d’un rang plus haut**, quelle que soit sa couleur (un 6 sur n’importe quel 7). N’importe quelle carte ou suite peut aller sur une colonne vide.
- Les cartes ne bougent ensemble que si elles se suivent **dans une même couleur**. Touchez une carte : elle part, avec les cartes posées dessus, vers la meilleure place. Touchez-la encore pour essayer la place suivante.
- Quand une carte face cachée est dégagée, elle se retourne toute seule.
- Touchez le **talon** (dans le coin, du côté de votre pouce) pour distribuer une nouvelle rangée : une carte sur chaque colonne. Il y a cinq rangées. Selon la règle classique, on ne peut distribuer que si **aucune colonne n’est vide** : si vous essayez, le jeu vous demande d’abord de remplir la colonne vide.
- **Annuler** revient en arrière, **Indice** montre un coup utile (ou vous dit de distribuer). S’il ne reste aucun coup utile et que le talon est vide, le jeu vous le dit : vous pouvez annuler quelques coups, abandonner ou continuer à chercher.

## Les règles au choix

Le nombre de couleurs fait la difficulté : il n’y a pas de niveau à choisir en plus.

- **Une couleur** : toutes les cartes sont des piques. La façon la plus facile, idéale pour apprendre.
- **Deux couleurs** : piques et cœurs. Il faut réfléchir davantage à la place de chaque carte.
- **Quatre couleurs** : les quatre couleurs. Un vrai défi : beaucoup de parties ne peuvent pas être gagnées.

## Conseils

- Le plus important est de retourner les cartes cachées : préférez les coups qui découvrent une carte.
- Construisez dans la même couleur dès que possible : les suites mélangées ne bougent pas ensemble.
- Une colonne vide est précieuse. Servez-vous-en pour ranger des cartes, pas seulement pour en garer une.
- Avant de distribuer une nouvelle rangée, jouez tous les coups utiles que vous voyez : les nouvelles cartes vont couvrir vos colonnes.
