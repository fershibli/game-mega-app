# Parejas

🌐 [English](../../en/games/memory.md) · [Português](../../pt-BR/games/memory.md) · **Español** · [Français](../../fr/games/memory.md) · [Italiano](../../it/games/memory.md) · [Deutsch](../../de/games/memory.md) · [Русский](../../ru/games/memory.md) · [日本語](../../ja/games/memory.md) · [中文](../../zh-CN/games/memory.md) · [العربية](../../ar/games/memory.md)

El clásico juego de memoria: todas las cartas están boca abajo y buscas las parejas iguales.

## Cómo se juega
Toca una carta para darle la vuelta y luego toca otra.
- **Mismo dibujo:** ¡una pareja! Las dos se quedan boca arriba (un poco atenuadas, con marco verde) y vuelves a jugar.
- **Dibujos distintos:** las dos se quedan boca arriba para que las mires con calma. Toca cualquier carta para seguir: las dos se vuelven a tapar (y la carta tocada se destapa, si estaba oculta).

No hay tiempo. Cada dos cartas destapadas cuentan como una **jugada**; intenta encontrar todas las parejas con las menos jugadas posibles. Tu récord se guarda para cada tipo de dibujo y cada nivel.

## Los dibujos
- **Naipes** — una pareja es el mismo número del mismo color: ♥ con ♦, o ♠ con ♣ (por ejemplo, el 7 de corazones con el 7 de diamantes).
- **Frutas** — manzana, pera, cerezas, plátano, limón, fresa, uvas, sandía, piña, naranja, aguacate, kiwi, calabaza, granada y coco.
- **Símbolos** — estrella, corazón, luna, sol, gota, hoja, flor, nube, rayo, gema, triángulo, anillo, signo más, casa y corona.
- **Animales** — gato, perro, conejo, oso, cerdo, ratón, búho, rana, pollito, pez, panda, zorro, león, vaca y oveja.

Cada dibujo tiene su propia forma, no solo su color, así que el juego sirve para cualquier tipo de visión de los colores.

## Niveles
| Nivel | Cartas | Parejas |
|---|---|---|
| Fácil | 3 × 4 | 6 |
| Medio | 4 × 4 | 8 |
| Difícil | 5 × 6 | 15 |

## Consejos
- Destapa primero una carta que nunca hayas visto; así ya sabes qué buscar.
- Di los dibujos en voz baja ("cerezas arriba a la izquierda"): ayuda a recordar.
