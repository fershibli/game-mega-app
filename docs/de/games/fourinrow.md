# Vier in einer Reihe

🌐 [English](../../en/games/fourinrow.md) · [Português](../../pt-BR/games/fourinrow.md) · [Español](../../es/games/fourinrow.md) · [Français](../../fr/games/fourinrow.md) · [Italiano](../../it/games/fourinrow.md) · **Deutsch** · [Русский](../../ru/games/fourinrow.md) · [日本語](../../ja/games/fourinrow.md) · [中文](../../zh-CN/games/fourinrow.md) · [العربية](../../ar/games/fourinrow.md)

Ein Spiel für zwei auf einem stehenden Holzgestell mit 7 Spalten und 6 Reihen von Löchern. Du spielst die hellen Scheiben und fängst an; der Computer spielt die dunklen. Wer zuerst vier Scheiben in eine Reihe bringt – waagerecht, senkrecht oder diagonal –, gewinnt.

## So wird gespielt

- Tippe irgendwo in eine Spalte, von oben bis unten auf dem Brett: Deine Scheibe fällt ins unterste freie Loch.
- Eine volle Spalte nimmt keine Scheiben mehr auf. Sind alle 42 Löcher ohne vier in einer Reihe gefüllt, endet das Spiel unentschieden.
- Die Gewinnreihe wird hervorgehoben.
- **Rückgängig** nimmt deinen letzten Zug zurück (und die Antwort des Computers). **Tipp** färbt eine gute Spalte ein.

## Stufen

- **Leicht**: nutzt immer einen Gewinn, blockiert deine meistens und denkt sonst nur zwei Züge voraus; manchmal wirft es eine Scheibe irgendwohin.
- **Mittel**: denkt sechs Züge voraus.
- **Schwer**: denkt so weit voraus, wie es in etwa zwei Drittelsekunden geht. Sehr schwer zu schlagen.

## Tipps

- Die mittlere Spalte ist die wertvollste: Durch sie laufen die meisten Viererreihen.
- Prüfe vor jedem Zug, ob der Computer nicht gewinnt, wenn er direkt auf deine Scheibe setzt.
- Bereite zwei Drohungen auf einmal vor, zum Beispiel eine direkt über der anderen: Der Computer kann nur eine blockieren.
