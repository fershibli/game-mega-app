# Brett-Solitär

🌐 [English](../../en/games/pegs.md) · [Português](../../pt-BR/games/pegs.md) · [Español](../../es/games/pegs.md) · [Français](../../fr/games/pegs.md) · [Italiano](../../it/games/pegs.md) · **Deutsch** · [Русский](../../ru/games/pegs.md) · [日本語](../../ja/games/pegs.md) · [中文](../../zh-CN/games/pegs.md) · [العربية](../../ar/games/pegs.md)

Ein ruhiges Denkspiel für eine Person, seit Jahrhunderten auf einem Holzbrett voller Kugeln gespielt.

## So wird gespielt
Tippe auf eine Kugel und dann auf das leere Loch **zwei Schritte weiter** in gerader Linie (nach oben, unten, links oder rechts, nie schräg). Die Kugel springt über ihre Nachbarin, und die übersprungene Kugel verlässt das Brett. Mach weiter, bis kein Sprung mehr möglich ist.

- **Eine Kugel übrig:** gewonnen!
- **Eine Kugel im markierten Loch** (ein kleiner goldener Ring): das perfekte Ende.
- **Mehrere Kugeln übrig, kein Sprung mehr:** Das Spiel endet ganz ruhig und sagt, wie viele übrig sind.

**Rückgängig** nimmt einen Sprung nach dem anderen zurück, so oft du willst. **Neu beginnen** stellt das Brett wieder wie am Anfang auf.

## Die Bretter
- **Englisches Brett** — 33 Löcher in Kreuzform. Alle sind besetzt außer der Mitte. Das perfekte Ende: die letzte Kugel in der Mitte.
- **Französisches Brett** — 37 Löcher: das Kreuz und je ein Loch in den inneren Ecken. Das mittlere Loch oben ist am Anfang leer, und das perfekte Ende ist die letzte Kugel im mittleren Loch unten (auf diesem Brett kann man nicht in der Mitte enden).

## Stufen
| Stufe | Start | Hilfe |
|---|---|---|
| Leicht | Ein schon halb gelöstes Brett (10 bis 12 Kugeln), immer bis auf eine lösbar | Kugeln, die springen können, haben einen Ring; nach der Auswahl leuchten ihre Ziellöcher |
| Mittel | Das volle Brett | Dieselben Markierungen wie bei Leicht |
| Schwer | Das volle Brett | Keine Markierungen |

## Tipps
- Lass keine einzelnen Kugeln weit weg von den anderen zurück: Eine Kugel ohne Nachbarn kann nie mehr entfernt werden.
- Räume einen Arm des Kreuzes nach dem anderen leer und arbeite dich zur Mitte zurück.
- Rückgängig kostet nichts. Probiere eine Idee aus, und wenn sie nicht weiterführt, nimm sie zurück.
