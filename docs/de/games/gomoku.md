# Gomoku (Fünf in einer Reihe)

🌐 [English](../../en/games/gomoku.md) · [Português](../../pt-BR/games/gomoku.md) · [Español](../../es/games/gomoku.md) · [Français](../../fr/games/gomoku.md) · [Italiano](../../it/games/gomoku.md) · **Deutsch** · [Русский](../../ru/games/gomoku.md) · [日本語](../../ja/games/gomoku.md) · [中文](../../zh-CN/games/gomoku.md) · [العربية](../../ar/games/gomoku.md)

Ein Spiel für zwei auf den Kreuzungspunkten eines 15×15-Bretts. Du spielst Schwarz und fängst an; der Computer spielt Weiß. Wer zuerst eine lückenlose Reihe aus fünf oder mehr Steinen bildet – waagerecht, senkrecht oder diagonal –, gewinnt.

## So wird gespielt

- Tippe auf einen Punkt: Ein blasser Stein zeigt, wohin er kommt. Tippe noch einmal auf denselben Punkt, um ihn zu setzen, oder auf einen anderen, wenn du es dir anders überlegst.
- Der zuletzt gesetzte Stein hat einen kleinen Ring, die Gewinnreihe wird hervorgehoben.
- **Rückgängig** nimmt deinen letzten Zug zurück (und die Antwort des Computers). **Tipp** markiert einen guten Punkt.

## Regeln

- Freier Stil: Fünf oder mehr in einer Reihe gewinnen, auch sechs oder mehr.
- Die Turnierbeschränkungen für Schwarz (kein „Doppel-Drei“, kein „Doppel-Vier“, keine Reihe länger als fünf) werden **nicht** verwendet, darum ist Schwarz, das anfängt, im Vorteil.
- Ist das Brett voll, endet das Spiel unentschieden.

## Stufen

- **Leicht**: wählt den vielversprechendsten Punkt, manchmal aber absichtlich einen schlechteren, und vergisst sogar gelegentlich, eine Vier zu blockieren.
- **Mittel**: vollendet immer die eigenen Vieren, blockiert deine und denkt ein paar Züge voraus.
- **Schwer**: denkt weiter voraus und sucht Gewinne durch eine Folge von Vieren, alles in weniger als einer Sekunde.

## Tipps

- Eine **offene Drei** (drei in einer Reihe mit beiden Enden frei) muss sofort blockiert werden, sonst wird sie zu einer offenen Vier, die nicht mehr aufzuhalten ist.
- Zwei Drohungen auf einmal gewinnen: Versuche, mit einem Stein eine Vier und eine offene Drei zu bilden.
