# Solitär

**Ziel:** Klondike — lege alle Karten auf die vier Ablagestapel (oben), vom Ass bis zum König, eine Farbe pro Stapel.

**So spielst du:** Tippe einfach **eine Karte an**. Sie wandert an die beste Stelle: wenn möglich auf einen Ablagestapel, sonst auf eine Reihe (abwechselnd Rot und Schwarz, einen Wert niedriger), sonst in eine leere Reihe (nur Könige). Kann sie nirgendwohin, blinkt sie rot. Tippst du eine offene Karte in einer Reihe an, wandert sie zusammen mit den Karten darauf. Tippe auf den **Stapel** (oben rechts, im Linkshänder-Modus oben links), um Karten zu ziehen; ist er leer, tippe darauf, um die abgelegten Karten wieder umzudrehen. **Tipp** umrandet einen sinnvollen Zug; **Zu Ende spielen** erscheint, wenn alle Karten aufgedeckt sind, und spielt den Rest für dich zu Ende.

| Stufe | Ziehen | Durchgänge durch den Stapel |
|---|---|---|
| Leicht | 1 Karte | unbegrenzt |
| Mittel | 3 Karten | unbegrenzt |
| Schwer | 3 Karten | 3 |
