# Rohre

**Ziel:** Drehe die Teile so, dass das Wasser aus der runden Quelle in der Mitte **jedes** Teil erreicht und kein Rohr gegen eine Wand oder eine geschlossene Seite zeigt.

Tippe ein Teil an, um es eine Vierteldrehung im Uhrzeigersinn zu drehen. Teile mit Wasser werden blau; Endstücke sind kleine Behälter, die sich füllen. **Tipp** dreht ein falsches Teil richtig. **Rückgängig** macht Drehungen rückgängig. Gitter: 5×5 / 7×7 / 9×9. Das Rätsel ist ein zufälliges Netz aus Rohren ohne Kreise, deshalb gibt es immer eine Lösung.
