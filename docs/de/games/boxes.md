# Kistenschieber

🌐 [English](../../en/games/boxes.md) · [Português](../../pt-BR/games/boxes.md) · [Español](../../es/games/boxes.md) · [Français](../../fr/games/boxes.md) · [Italiano](../../it/games/boxes.md) · **Deutsch** · [Русский](../../ru/games/boxes.md) · [日本語](../../ja/games/boxes.md) · [中文](../../zh-CN/games/boxes.md) · [العربية](../../ar/games/boxes.md)

Führe den runden Freund durch den Raum und schiebe jede Kiste auf einen runden Punkt.

## So wird gespielt
- Wische, nutze die Pfeile oder tippe ein Feld an, um dorthin zu gehen.
- Laufe gegen eine Kiste, um sie ein Feld zu schieben. Kisten lassen sich nur schieben, nie ziehen, und immer nur eine.
- **Rückgängig** so oft du willst; **Neu beginnen** startet den Raum neu; **Tipp** zeigt den nächsten Schritt.
- Steckt eine Kiste fest und kann keinen Punkt mehr erreichen, sagt das Spiel es: Tippe auf Rückgängig, um sie zu befreien.

## Stufen
- **Leicht:** 2 Kisten in einem kleinen Raum.
- **Mittel:** 3 Kisten.
- **Schwer:** 4 Kisten in einem größeren Raum mit mehr Wänden.

## Tipps
- Überlege, bevor du eine Kiste an die Wand schiebst: Von dort gleitet sie nur noch an der Wand entlang.
- Eine Kiste in einer Ecke kommt nicht mehr heraus: Meide Ecken ohne Punkt.
