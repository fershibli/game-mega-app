# Empurra-caixas

🌐 [English](../../en/games/boxes.md) · **Português** · [Español](../../es/games/boxes.md) · [Français](../../fr/games/boxes.md) · [Italiano](../../it/games/boxes.md) · [Deutsch](../../de/games/boxes.md) · [Русский](../../ru/games/boxes.md) · [日本語](../../ja/games/boxes.md) · [中文](../../zh-CN/games/boxes.md) · [العربية](../../ar/games/boxes.md)

Leve o amiguinho redondo pela sala e empurre cada caixa até um ponto redondo.

## Como jogar
- Deslize o dedo, use as setas ou toque num quadrado para andar até ele.
- Ande contra uma caixa para empurrá-la uma casa. Caixas só podem ser empurradas, nunca puxadas, e uma de cada vez.
- **Desfazer** quantas vezes quiser; **Recomeçar** volta a sala do início; **Dica** mostra o próximo passo.
- Se uma caixa ficar presa onde não chega mais a um ponto, o jogo avisa: toque em Desfazer para soltá-la.

## Níveis
- **Fácil:** 2 caixas numa sala pequena.
- **Médio:** 3 caixas.
- **Difícil:** 4 caixas numa sala maior, com mais paredes.

## Dicas
- Pense antes de encostar uma caixa na parede: dali ela só desliza junto à parede.
- Caixa no canto não sai mais, então evite cantos sem ponto.
