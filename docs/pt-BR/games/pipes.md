# Encanamento

**Objetivo:** girar as peças para que a água da fonte redonda no meio chegue a **todas** as peças, sem nenhum cano apontando para a parede ou para um lado fechado.

Toque numa peça para girá-la um quarto de volta no sentido horário. Peças com água ficam azuis; as pontas são caixinhas d'água que enchem. **Dica** coloca uma peça errada no lugar. **Desfazer** volta os giros. Grade: 5×5 / 7×7 / 9×9. O desafio é uma "árvore" de canos aleatória, sem circuitos fechados, e sempre tem solução.
