# Criptograma

🌐 [English](../../en/games/cryptogram.md) · **Português** · [Español](../../es/games/cryptogram.md) · [Français](../../fr/games/cryptogram.md) · [Italiano](../../it/games/cryptogram.md) · [Deutsch](../../de/games/cryptogram.md) · [Русский](../../ru/games/cryptogram.md) · [日本語](../../ja/games/cryptogram.md) · [中文](../../zh-CN/games/cryptogram.md) · [العربية](../../ar/games/cryptogram.md)

Um ditado conhecido está escrito em código: cada letra foi trocada por outro símbolo. Descubra que letra se esconde atrás de cada símbolo e o ditado aparece.

## Como jogar

- Cada quadrado mostra o seu símbolo em letra pequena embaixo de uma linha. No **Fácil** os símbolos são números (1, 2, 3...); nos outros níveis são outras letras. Uma letra nunca se esconde atrás dela mesma.
- Toque em um quadrado: todos os quadrados com o mesmo símbolo se acendem. Depois toque na letra que você acha que ele esconde: ela é escrita em todos esses quadrados de uma vez.
- Se você usar uma letra que já estava em outro símbolo, ela muda para cá. O botão ⌫ apaga a letra do símbolo escolhido.
- As letras com fundo verde foram reveladas e estão sempre certas.
- **Dica** escreve a letra certa no símbolo escolhido (ou no primeiro que ainda não está certo).
- Quando todas as letras estão certas, o ditado inteiro aparece.

Todos os ditados são provérbios populares tradicionais. Os acentos não são escritos (É vira E, Ç vira C).

O criptograma é jogado em português, inglês, espanhol, francês, italiano, alemão, russo e árabe. Japonês e chinês não são escritos com um alfabeto pequeno de letras que possam ser trocadas, por isso nesses idiomas o jogo pergunta primeiro em qual destas línguas jogar.

## Níveis

- **Fácil**: números no lugar das letras e três letras já reveladas.
- **Médio**: letras, uma revelada.
- **Difícil**: letras, nenhuma revelada.

## Dicas

- Comece pelas palavras curtas: uma palavra de uma letra só costuma ser A, E, O ou É.
- Um símbolo que aparece muitas vezes provavelmente é uma vogal (A, E, O) ou uma letra comum como S ou R.
- Lembre dos ditados conhecidos: com algumas letras no lugar, o resto muitas vezes vem sozinho.
