# Tangram

🌐 [English](../../en/games/tangram.md) · **Português** · [Español](../../es/games/tangram.md) · [Français](../../fr/games/tangram.md) · [Italiano](../../it/games/tangram.md) · [Deutsch](../../de/games/tangram.md) · [Русский](../../ru/games/tangram.md) · [日本語](../../ja/games/tangram.md) · [中文](../../zh-CN/games/tangram.md) · [العربية](../../ar/games/tangram.md)

Sete peças planas (dois triângulos grandes, um médio, dois pequenos, um quadrado e um paralelogramo) formam uma figura. Preencha a figura com as sete peças, sem sobrepor.

## Como jogar
- Arraste uma peça para movê-la e toque nela para girar.
- **Virar** vira o paralelogramo do avesso.
- As peças se encaixam sozinhas quando chegam perto. **Dica** coloca uma peça; **Recomeçar** tira todas.

## Níveis
- **Fácil:** o contorno de cada peça aparece dentro da figura.
- **Médio:** três peças aparecem desenhadas.
- **Difícil:** só a figura.

## Dicas
- Comece pelos dois triângulos grandes: eles ocupam quase toda a figura.
