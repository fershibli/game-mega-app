# Paciência Spider

🌐 [English](../../en/games/spider.md) · **Português** · [Español](../../es/games/spider.md) · [Français](../../fr/games/spider.md) · [Italiano](../../it/games/spider.md) · [Deutsch](../../de/games/spider.md) · [Русский](../../ru/games/spider.md) · [日本語](../../ja/games/spider.md) · [中文](../../zh-CN/games/spider.md) · [العربية](../../ar/games/spider.md)

Uma paciência com dois baralhos (104 cartas) em dez colunas. Monte sequências do **Rei ao Ás do mesmo naipe**: assim que uma sequência fica completa, ela sai da mesa sozinha. Complete as oito sequências para ganhar.

## Como jogar

- São distribuídas 54 cartas: seis em cada uma das quatro primeiras colunas, cinco nas outras, só a última carta de cada coluna virada para cima.
- Você pode pôr uma carta sobre qualquer carta **um valor acima**, de qualquer naipe (um 6 sobre qualquer 7). Qualquer carta ou sequência pode ir para uma coluna vazia.
- As cartas só se movem juntas quando estão em ordem **do mesmo naipe**. Toque numa carta: ela vai, com as cartas de cima, para o melhor lugar. Toque de novo para tentar o próximo lugar.
- Quando uma carta virada para baixo fica livre, ela se vira sozinha.
- Toque no **monte** (no canto do lado do seu polegar) para distribuir uma nova fileira: uma carta em cada coluna. São cinco fileiras. Pela regra clássica, só dá para distribuir quando **nenhuma coluna está vazia**: se você tentar, o jogo avisa para preencher a coluna vazia primeiro.
- **Desfazer** volta jogadas, **Dica** mostra uma jogada útil (ou diz para distribuir). Se não houver mais jogadas úteis e o monte acabou, o jogo avisa: você pode desfazer algumas jogadas, desistir ou continuar procurando.

## As regras que você pode escolher

O número de naipes é a dificuldade, então não há nível separado para escolher.

- **Um naipe**: todas as cartas são de espadas. O jeito mais fácil e o melhor para aprender.
- **Dois naipes**: espadas e copas. É preciso pensar mais em onde pôr cada carta.
- **Quatro naipes**: os quatro naipes. Um desafio de verdade: muitos jogos não têm solução.

## Dicas

- Virar as cartas de baixo é o mais importante: prefira jogadas que descobrem uma carta.
- Sempre que puder, monte sobre cartas do mesmo naipe: sequências misturadas não se movem juntas.
- Uma coluna vazia vale ouro. Use-a para arrumar cartas, não só para guardar uma.
- Antes de distribuir uma nova fileira, faça todas as jogadas úteis que encontrar: as cartas novas vão cobrir suas colunas.
