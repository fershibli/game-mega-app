# Mahjong

**Objetivo:** retirar todas as peças, em pares iguais.

Uma peça está **livre** quando não há nenhuma peça em cima dela e o lado esquerdo **ou** o direito está desocupado. Toque em duas peças livres iguais para retirá-las. Quaisquer duas **flores** combinam entre si, e quaisquer duas **estações** também. Cada peça de naipe tem no canto um número ocidental pequeno (ou E/S/W/N para os ventos), então não é preciso ler chinês.

No Fácil e no Médio, as peças **que não estão livres ficam escurecidas**. **Dica** contorna um par, **Desfazer** devolve o último par, **Embaralhar** redistribui as peças que sobraram quando você fica sem jogadas.

| Nível | Peças | Embaralhadas |
|---|---|---|
| Fácil | 48 (torre) | ilimitadas |
| Médio | 96 (fortaleza) | 3 |
| Difícil | 144 (tartaruga clássica) | 1 |

Cada distribuição é montada para **sempre ter solução**.
