# Paciência

**Objetivo:** Klondike — levar todas as cartas para as quatro pilhas de cima, do Ás ao Rei, uma pilha por naipe.

**Como jogar:** basta **tocar na carta**. Ela vai para o melhor lugar: para cima, se der; senão para uma coluna (cores alternadas, uma carta abaixo); senão para uma coluna vazia (só Reis). Se não puder ir a lugar nenhum, ela pisca em vermelho. Tocar numa carta virada para cima no meio de uma coluna move ela junto com as que estão em cima. Toque no **monte** (canto superior direito, ou esquerdo no modo canhoto) para virar cartas; quando acabar, toque nele para recolocar o descarte. **Dica** contorna uma jogada útil; **Terminar** aparece quando todas as cartas estão viradas e completa o jogo para você.

| Nível | Vira | Voltas no monte |
|---|---|---|
| Fácil | 1 carta | ilimitadas |
| Médio | 3 cartas | ilimitadas |
| Difícil | 3 cartas | 3 |
