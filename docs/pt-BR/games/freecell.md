# Células livres

Uma paciência em que **todas as cartas ficam viradas para cima** desde o começo: tudo depende de pensar antes. Monte quatro pilhas do **Ás ao Rei, uma de cada naipe**. Quase todas as distribuições têm solução, e neste app todas têm.

## Como jogar

- As 52 cartas são distribuídas em oito colunas. Acima delas ficam as **quatro células livres** (do lado do seu polegar) e as **quatro pilhas finais**, uma por naipe.
- Nas colunas, uma carta vai sobre uma carta **um valor acima e da outra cor** (um 6 vermelho sobre um 7 preto). Qualquer carta pode ir para uma coluna vazia.
- Cada célula livre guarda **uma carta**, para tirá-la do caminho por um tempo.
- Toque numa carta: ela vai para o melhor lugar (primeiro para a pilha final, depois outra coluna, uma célula livre e por fim uma coluna vazia). Toque de novo para tentar o próximo lugar.
- Dá para mover várias cartas em ordem de uma vez se houver espaço para carregá-las: (células livres + 1), dobrado para cada coluna vazia. Se não houver espaço, o jogo diz quantas cartas você pode mover agora.
- Quando todas as colunas estão em ordem, **Terminar** manda todas as cartas para as pilhas.
- **Desfazer** volta jogadas. **Dica** pede a um resolvedor a próxima jogada de um caminho vencedor. Depois de cada jogada o jogo verifica se ainda dá para ganhar; se não der, ele avisa e você pode desfazer, desistir ou continuar procurando.

## Níveis

Cada distribuição é verificada por um resolvedor antes de aparecer, então sempre dá para ganhar.

- **Fácil**: distribuições que o resolvedor ganha usando só duas das quatro células livres. Com as quatro, sobra espaço.
- **Médio**: distribuições que precisam de três células livres.
- **Difícil**: distribuições que precisam das quatro células livres e de bom planejamento.

## Dicas

- Libere primeiro os Ases e os Dois: procure-os embaixo de outras cartas.
- Mantenha as células livres vazias o máximo possível; com todas cheias, tudo trava.
- Uma coluna vazia vale mais que uma célula: ela dobra quantas cartas você pode mover.
- Antes de mover, pense algumas jogadas à frente: para onde vai a carta que você vai descobrir?
