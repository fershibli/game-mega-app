# Nonograma

🌐 [English](../../en/games/nonogram.md) · **Português** · [Español](../../es/games/nonogram.md) · [Français](../../fr/games/nonogram.md) · [Italiano](../../it/games/nonogram.md) · [Deutsch](../../de/games/nonogram.md) · [Русский](../../ru/games/nonogram.md) · [日本語](../../ja/games/nonogram.md) · [中文](../../zh-CN/games/nonogram.md) · [العربية](../../ar/games/nonogram.md)

Pintar por números. Os números ao lado de cada linha e acima de cada coluna dão o tamanho dos blocos pintados daquela linha, em ordem; entre dois blocos há pelo menos um quadrado vazio. Pinte os quadrados certos e aparece uma figura: no final, ela é mostrada colorida e com o nome.

## Como jogar

- Toque num quadrado para pintá-lo; toque de novo para apagar.
- Segure um quadrado para marcá-lo com ✕ (um quadrado que você sabe que fica vazio). Com **Marcar** ligado, o toque marca ✕ e segurar pinta.
- Arraste por uma linha ou coluna para pintar (ou marcar) vários quadrados de uma vez.
- Os números de uma linha ficam claros quando os quadrados pintados correspondem a eles.
- **Desfazer** volta a última mudança. **Dica** primeiro corrige um erro; senão, pinta um quadrado que uma linha já decide.
- Use o gesto de pinça para ampliar as grades maiores.

## Níveis

- **Fácil**: 5×5. Os erros aparecem em vermelho.
- **Médio**: 10×10. Os erros aparecem em vermelho.
- **Difícil**: 15×15. Os erros não aparecem.

Todo desafio pode ser resolvido uma linha de cada vez, sem chutar. As figuras (mais de 20 para cada tamanho: bichos, flores, uma casa, um barco, um bule...) foram desenhadas para este app; se nenhuma servir, usa-se um desenho geométrico aleatório.

## Dicas

- Comece pelos números grandes: um bloco de 8 numa linha de 10 sempre cobre os 6 quadrados do meio.
- Uma linha com 0 fica toda vazia: marque com ✕.
- Marque os quadrados vazios com ✕: eles ajudam as linhas que os cruzam.
