# Palavras cruzadas

Uma **cruzadinha nova é gerada** a cada partida, a partir de um dicionário de palavras do dia a dia com dicas simples, no idioma do app. As palavras das últimas partidas ficam de fora da próxima, para não repetir.

**Níveis:** no **Fácil** a primeira letra de cada palavra já vem preenchida (em azul) e aparecem as letras para tocar; no **Médio** a grade é maior, com mais palavras; no **Difícil** a grade é a maior, os erros não ficam vermelhos e, em português, entram palavras menos comuns (o dicionário em português marca cada palavra como fácil, média ou difícil).

**Como jogar:** toque num quadradinho para escolher a palavra; toque de novo no mesmo para trocar entre horizontal e vertical. A dica aparece embaixo, entre ◀ e ▶ (palavra anterior / próxima). Digite com as letras embaixo: depois de cada letra o cursor avança. A borracha apaga uma letra. **Dica** preenche o quadradinho selecionado.

Os acentos são ignorados como nas revistas de palavras cruzadas (Ç = C, É = E…); o espanhol mantém o Ñ, o alemão escreve Ä Ö Ü ß como AE OE UE SS e o russo escreve Ё como Е. Em chinês, cada quadradinho tem um caractere; em japonês, um katakana, com os kana pequenos escritos em tamanho normal (ッ → ツ); em árabe, uma letra sem sinais de vogal (أ إ آ viram ا), e as palavras na horizontal são lidas da direita para a esquerda.

| Nível | Grade | Como digitar | Erros em vermelho |
|---|---|---|---|
| Fácil | 9×9 (8×8 em chinês e japonês), ~7 palavras (~6) | banco de letras (letras da palavra + 2 a mais) | sim |
| Médio | 11×11 (10×10), ~11 palavras (~9) | teclado completo no layout do idioma (chinês, japonês e árabe: banco com 5 a mais) | sim |
| Difícil | 13×13 (12×12), ~16 palavras (~12) | teclado completo (chinês, japonês e árabe: banco com 8 a mais) | não |

O francês usa teclado AZERTY, o alemão QWERTZ, o russo ЙЦУКЕН e os outros, QWERTY.
