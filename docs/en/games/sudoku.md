# Sudoku

**Goal:** fill the 9×9 grid so every row, column and 3×3 box contains 1 to 9 once.

**Playing:** tap a square, then a number at the bottom. Tap the eraser to clear. **Notes** switches the number pad to pencil marks (small reminders); placing a number removes that note from the same row, column and box automatically. **Hint** fills the selected square (or a random one) with the right number. **Undo** steps back.

Helpers: the row, column and box of the selected square are shaded, equal numbers are highlighted, and a number button fades when all nine are placed.

| Level | Starting numbers | Mistakes shown in red |
|---|---|---|
| Easy | 40 | yes |
| Medium | 32 | yes |
| Hard | 26 | only rule conflicts |

Every puzzle is generated new and has exactly **one** solution.
