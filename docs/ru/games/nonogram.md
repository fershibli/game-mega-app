# Японский кроссворд

🌐 [English](../../en/games/nonogram.md) · [Português](../../pt-BR/games/nonogram.md) · [Español](../../es/games/nonogram.md) · [Français](../../fr/games/nonogram.md) · [Italiano](../../it/games/nonogram.md) · [Deutsch](../../de/games/nonogram.md) · **Русский** · [日本語](../../ja/games/nonogram.md) · [中文](../../zh-CN/games/nonogram.md) · [العربية](../../ar/games/nonogram.md)

Рисование по числам. Числа слева от каждой строки и над каждым столбцом показывают длины закрашенных блоков этого ряда по порядку; между двумя блоками есть хотя бы одна пустая клетка. Закрасьте нужные клетки, и появится картинка: в конце она показывается в цвете и с названием.

## Как играть

- Нажмите на клетку, чтобы закрасить её; нажмите ещё раз, чтобы стереть.
- Удерживайте клетку, чтобы поставить ✕ (клетка, которая точно пустая). Если включено **Отметить**, нажатие ставит ✕, а удержание закрашивает.
- Проведите пальцем вдоль строки или столбца, чтобы закрасить (или отметить) несколько клеток сразу.
- Числа ряда бледнеют, когда закрашенные клетки им соответствуют.
- **Отменить ход** убирает последнее изменение. **Подсказка** сначала исправляет ошибку, а если ошибок нет, закрашивает клетку, которую уже определяет один ряд.
- Большие сетки можно увеличить двумя пальцами.

## Уровни

- **Легко**: 5×5. Ошибки показываются красным.
- **Средне**: 10×10. Ошибки показываются красным.
- **Сложно**: 15×15. Ошибки не показываются.

Каждую задачу можно решить ряд за рядом, без угадывания. Картинки (больше 20 для каждого размера: животные, цветы, домик, кораблик, чайник...) нарисованы для этого приложения; если ни одна не подходит, используется случайный узор.

## Советы

- Начинайте с больших чисел: блок из 8 в ряду из 10 всегда покрывает 6 средних клеток.
- Ряд с числом 0 целиком пустой: отметьте его ✕.
- Отмечайте пустые клетки ✕: они помогают пересекающим рядам.
