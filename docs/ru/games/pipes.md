# Трубы

**Цель:** повернуть детали так, чтобы вода от круглого источника в центре дошла до **каждой** детали и ни одна труба не упиралась в стенку или в закрытую сторону.

Коснитесь детали, чтобы повернуть её на четверть оборота по часовой стрелке. Детали с водой становятся синими; концевые детали — это маленькие баки, которые наполняются водой. **Подсказка** ставит на место одну неправильно повёрнутую деталь. **Отменить ход** отменяет повороты. Поле: 5×5 / 7×7 / 9×9. Головоломка — это случайное «дерево» труб, поэтому в нём нет замкнутых колец и решение есть всегда.
