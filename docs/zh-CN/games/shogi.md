# 日本将棋

🌐 [English](../../en/games/shogi.md) · [Português](../../pt-BR/games/shogi.md) · [Español](../../es/games/shogi.md) · [Français](../../fr/games/shogi.md) · [Italiano](../../it/games/shogi.md) · [Deutsch](../../de/games/shogi.md) · [Русский](../../ru/games/shogi.md) · [日本語](../../ja/games/shogi.md) · **中文** · [العربية](../../ar/games/shogi.md)

日本将棋是日本的象棋。它最大的特点是：**吃掉的棋子会变成你的**，以后可以当作自己的棋子“打”回棋盘上。

**在这部手机上轮流玩：** 两个人也可以不用电脑，互相对战。棋盘不会转动，屏幕会显示轮到谁。 每位玩家吃到的棋子放在自己那一边。

## 选择规则

- **将棋（9×9）**：完整的游戏，每方20枚棋子。
- **五五将棋（5×5）**：小棋盘，每种棋子各一枚（王、飞车、角行、金、银、步）。一盘很快就下完，适合入门。

## 棋盘和棋子

- 棋子放在**格子里**。所有棋子颜色相同：你的**尖头朝上**，电脑的尖头朝下（颜色也稍深）。
- 你从下方先走。
- 每枚棋子上，**点**表示朝那个方向走一步，**箭头**表示可以走任意远。红字是升变后的棋子。

| 棋子 | 走法 | 升变后 |
|---|---|---|
| 王将 王 / 玉 | 任何方向走一步。 | — |
| 飞车 飛 | 横竖走任意远。 | 龙王 龍：还能斜走一步。 |
| 角行 角 | 斜走任意远。 | 龙马 馬：还能横竖走一步。 |
| 金将 金 | 除了斜后方，任何方向走一步。 | 不能升变。 |
| 银将 銀 | 向前或斜向走一步。 | 走法同金将（全）。 |
| 桂马 桂 | 跳到前方两格再偏一格（上方两个点）。 | 走法同金将（圭）。 |
| 香车 香 | 一直向前走任意远。 | 走法同金将（杏）。 |
| 步兵 歩 | 向前走一步。 | と金 と：走法同金将。 |

随时点“棋子”按钮，就能看到大图。

## 升变

对面的三行（五五将棋是一行）是**升变区**，带有淡淡的颜色。棋子走进、在里面走或走出升变区时，应用会用两个大按钮问你：“升变”还是“保持原样”。如果不升变就再也不能走（最后一行的步和香车、最后两行的桂马），就会自动升变。

## 打入

吃掉的棋子放在棋盘下方，成为你的**持驹**。不走棋时，可以点一枚持驹，再点一个绿色的格子把它打到那里。规则：

- 打入的棋子当时不能升变；
- 同一列不能有两枚你自己的未升变的步（二步）；
- 打步不能**直接将死**对方（打步诘），其他棋子可以；
- 不能打到再也走不动的地方（最后一行的步和香车，最后两行的桂马）。

## 怎样赢

将死电脑的王就赢。同一局面出现**四次**（千日手）算和棋。

## 在应用里怎么下

1. 点棋盘上或手中的一枚棋子，绿点会显示它能走到哪里。
2. 点一个绿点。问你是否升变时，选择一个答案。
3. “撤销”会收回你上一步和电脑的应着；“提示”会指出一步好棋。

## 难度

- **简单**：只看一步，经常走错。
- **中等**：看几步。
- **困难**：在一秒之内想得尽量深。

## 简化的地方

不采用“连续将军的千日手判将军方负”的规则：所有四次重复都算和棋。对局达到400手算和棋。不使用入玉的计分（持将棋）。

## 小窍门

- 打入很厉害：把吃来的金或银打在对方王的旁边，常常能决定胜负。
- 用金将和银将围成一道墙，保护自己的王。
- 能升变时一般就升变，不升变的银或桂更有用的情况很少。
