# 贪吃蛇

一条慢悠悠、友好的小蛇在格子上爬行。带它去吃水果（苹果、樱桃、草莓和梨）：每吃一个就长一格。不用着急：只有游戏进行时小蛇才会移动，你随时可以暂停。

## 玩法
- 用**四个大箭头**（或在棋盘上滑动）选择方向。按下箭头也会开始游戏。
- **暂停**让小蛇停下。打开设置或离开应用时游戏也会自动暂停；点**继续**接着玩。
- 会显示长度和该难度的最佳长度。即使玩其他游戏，最佳长度也会保留。

## 难度
- **简单：** 很慢。小蛇能穿过边缘从另一侧出来；碰到自己只会失去尾巴末端，游戏不会结束。
- **中等：** 较慢。依然能穿过边缘，但碰到自己游戏结束。
- **困难：** 稍快，边缘是墙：撞墙或碰到自己游戏结束。

## 小技巧
- 提前规划转弯：小蛇最多记住两次箭头操作。
- 沿着边缘走，可以把中间留给长长的身体。
