# 数织

🌐 [English](../../en/games/nonogram.md) · [Português](../../pt-BR/games/nonogram.md) · [Español](../../es/games/nonogram.md) · [Français](../../fr/games/nonogram.md) · [Italiano](../../it/games/nonogram.md) · [Deutsch](../../de/games/nonogram.md) · [Русский](../../ru/games/nonogram.md) · [日本語](../../ja/games/nonogram.md) · **中文** · [العربية](../../ar/games/nonogram.md)

按数字涂色。每行左边和每列上方的数字按顺序表示这一行（列）里各段涂色方格的长度，两段之间至少空一格。涂对方格就会出现一幅图画：完成时会显示彩色的图画和它的名字。

## 玩法

- 点一下方格涂色，再点一下擦掉。
- 长按方格标记✕（确定留空的方格）。打开**标记**后，点一下标记✕，长按则涂色。
- 沿着一行或一列拖动，可以一次涂（或标记）好几个方格。
- 当一行涂好的方格和数字相符时，这些数字会变淡。
- **撤销**取消上一步。**提示**先改正一个错误；没有错误时，涂一个只看一行就能确定的方格。
- 大的格子可以用双指放大。

## 难度

- **简单**：5×5，错误显示为红色。
- **中等**：10×10，错误显示为红色。
- **困难**：15×15，不显示错误。

每道题都可以一行一行推理出来，不需要猜。图画（每种大小20多幅：动物、花、房子、船、茶壶……）都是为这个应用绘制的；如果没有合适的，就用随机图案。

## 小窍门

- 先看大数字：长度为10的一行里有一段8，中间6格一定要涂。
- 数字是0的一行全部留空，标上✕。
- 给空格标上✕，对和它交叉的行列有帮助。
