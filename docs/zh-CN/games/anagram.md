# 词语重组

🌐 [English](../../en/games/anagram.md) · [Português](../../pt-BR/games/anagram.md) · [Español](../../es/games/anagram.md) · [Français](../../fr/games/anagram.md) · [Italiano](../../it/games/anagram.md) · [Deutsch](../../de/games/anagram.md) · [Русский](../../ru/games/anagram.md) · [日本語](../../ja/games/anagram.md) · **中文** · [العربية](../../ar/games/anagram.md)

一个词的字被打乱了，把它们按正确的顺序排回来吧！

## 玩法

- 按正确的顺序点大字块，每个字会放到答案的下一个空位。
- 点答案里的字，可以把它拿回来。**撤销**拿回最后一个字。**打乱**会重新打乱字块，有时这样更容易看出是什么词。
- 拼对以后，词会变色，然后出现下一个词。每轮五个词。
- **提示**会放上下一个正确的字（先拿回放错的字）。用提示一定能完成每个词。
- 如果这些字还能组成词库里的另一个词，也算对。

## 难度

中文按汉字个数计算，只出三个字或更长的词：

- **简单**：三个字的词；显示提示语，第一个字已经放好。
- **中等**：三到四个字，显示提示语。
- **困难**：四个字（常是成语），不显示提示语：第一次点**提示**才会出现。

其他语言按字母计算：简单 4–5 个，中等 6–7 个，困难 8 个以上。

## 小窍门

- 先读提示语，想想这个词的意思。
- 先放有把握的字，其余的再慢慢试。
