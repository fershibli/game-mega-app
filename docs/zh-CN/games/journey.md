# 旅程

🌐 [English](../../en/games/journey.md) · [Português](../../pt-BR/games/journey.md) · [Español](../../es/games/journey.md) · [Français](../../fr/games/journey.md) · [Italiano](../../it/games/journey.md) · [Deutsch](../../de/games/journey.md) · [Русский](../../ru/games/journey.md) · [日本語](../../ja/games/journey.md) · **中文** · [العربية](../../ar/games/journey.md)

一场轻松的回合制冒险，发生在城堡与骑士的王国里，还有来自巴西民间传说的朋友。没人催你：敌人会等你出手，输了也不会失去任何东西。

## 开始
选择一个**职业**，再输入**名字**：

| 职业 | 擅长 |
|---|---|
| 骑士 | 生命多，会**重击**。 |
| 弓箭手 | 动作快，**箭雨**能射中所有敌人。 |
| 法师 | **火**与**冰**的魔法。 |
| 治疗师 | 用**光**治疗队伍。 |

铁匠**本托**从一开始就和你同行：他会**守护**队伍，替大家挨打。在森林里你可以救出火焰法师**莉亚**。

## 地图和村庄
点地图上的地点就能前往。前一个地点完成后，下一个才会开放；赢过的战斗可以再打，让自己变强。宝箱和朋友会给你药水、以太和金币。在**村庄**里可以**在旅店休息**（大家恢复满生命和法力）、向**萨西**请教窍门，还能随时改变敌人的强度（简单、中等、困难）。

## 战斗
顶部的条显示接下来轮到谁：速度快的先行动。轮到你时选择：
- **攻击**，再选对象。
- **魔法**：每个魔法都消耗法力。
- **防御**：到你下次行动前伤害减半，并恢复一点法力。
- **道具**：药水恢复一半生命，以太恢复法力。
- **最佳行动**替你走一步好棋，**自动**会替整个队伍行动。

每个敌人都**怕**某种魔法（伤害1.5倍），又能**抵抗**另一种（伤害减半）。第一次打中后，大图标会显示它的弱点。敌人不会死：它们会逃跑或晕倒。

| 敌人 | 弱点 | 抵抗 |
|---|---|---|
| 绿色黏液 | 火 | 冰 |
| 野猪 | 冰 | 火 |
| 瞌睡蘑菇 | 火 | 光 |
| 灰狼 | 光 | 冰 |
| 巨型野猪（首领） | 冰 | 火 |

如果全队晕倒，会在旅店醒来，休息好了，东西一样不少。

## 等级
战斗能获得经验和金币。每升一级，你可以选一项奖励：更多生命、攻击、防御、法力或速度，或者学会新魔法。

## 五个地区
地图上有箭头，可以在地区之间切换。前一个地区的首领逃走后，下一个地区才会开放。

| 地区 | 要救的朋友 | 敌人，以及它们怕什么 | 首领 |
|---|---|---|---|
| 森林 | 莉亚（火焰法师） | 黏液（火）、野猪（冰）、蘑菇（火）、狼（光） | 巨型野猪（冰） |
| 河流 | 伊阿拉（治疗、守护、淋湿） | 青蛙（冰）、螃蟹（自然）、食人鱼（光） | 巨型螃蟹（自然） |
| 丘陵 | 泽卡（盗贼：偷东西、扔油瓶） | 蝙蝠（光）、地精（火）、小石怪（自然） | 丘陵巨魔（奥术） |
| 遗迹 | 蒂托（让敌人睡着） | 小幽灵（光）、空盔甲（奥术）、蜘蛛（火） | 古老魔像（奥术） |
| 城堡 | 朵拉（吟游诗人：大家都有勇气） | 小恶魔（冰）、石像鬼（自然）、黑暗骑士（光） | 影子国王（光） |

每个地区还有一位友善的角色给你提示（博托、凯波拉、智慧猫头鹰、老卫兵），有些宝箱里还有能教主角魔法的**卷轴**。

## 商店和酒馆
- 村庄**商店**：药水、以太、剑（攻击）、盔甲（防御）和护符（法力）。买过的东西一直是你的；点**装备**就能更换。
- 最多**三个朋友**和主角同行。其他人在**酒馆**等着，你可以在那里选择谁出发。战斗中，**换伙伴**能从酒馆叫人上场（会用掉这一回合）。

## 更多魔法
- **自然**：荆棘（中毒：每回合损失一点生命）、藤蔓（所有敌人，变慢）、水浪（把敌人淋湿）。
- **奥术**：奥术飞弹、催眠（被打之前一直跳过回合；首领只会打个盹）、屏障（一段时间内伤害减半）、勇气之歌（攻击更强）。
- **连招**：**淋湿**的敌人被**冰**打中会冻住（伤害更高，还要停一回合）；**浑身是油**的敌人被**火**打中会烧得加倍厉害。
