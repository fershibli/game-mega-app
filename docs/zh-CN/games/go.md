# 围棋

🌐 [English](../../en/games/go.md) · [Português](../../pt-BR/games/go.md) · [Español](../../es/games/go.md) · [Français](../../fr/games/go.md) · [Italiano](../../it/games/go.md) · [Deutsch](../../de/games/go.md) · [Русский](../../ru/games/go.md) · [日本語](../../ja/games/go.md) · **中文** · [العربية](../../ar/games/go.md)

一种源自东亚、已有几千年历史的双人棋类游戏：你执黑棋，电脑执白棋。棋子下在线的交叉点上，落下后不再移动。目标是比对手围住更大的地盘。

## 怎么玩

- 点一个交叉点即可落子。在13路和19路棋盘上交叉点较小：第一次点会显示一颗半透明的棋子，再点一次同一个交叉点才会落子。
- 沿线相连的棋子组成一块棋。一块棋旁边至少要有一个空的交叉点（称为**气**）。最后一口气被堵住时，这块棋就被**提掉**，从棋盘上拿走。
- 不能下在会让自己的棋子没有气的地方，除非这一手能提掉对方的棋子。
- **打劫**：刚刚被提掉一颗子时，不能立刻在同一个地方提回来。请先在别处下一手。
- 没有有用的棋可下时，点**停一手**。双方接连停一手，对局就结束。
- 最后一手棋上有一个小圆圈。提子的数目显示在上方。
- **撤销**会收回你的上一步（以及电脑的应手）。**提示**会标出一个好的交叉点。

## 计算胜负

- 我们使用数子法（中国规则）：每方棋盘上的每颗棋子，以及只被自己棋子围住的每个空交叉点，各算一分。
- 白棋后走，因此加6.5分（**贴目**）。有半分，所以不会和棋。
- 双方停一手后，电脑会提出哪些棋块是**死棋**（无法逃脱被提）：它们会画上叉，地盘用小方块表示。点一个棋块可以在死活之间切换，然后点**数子**。如果你不同意，点**继续下**，在棋盘上分出结果。

## 棋盘

- **9路**：小而快，最适合入门。
- **13路**：布局空间更大。
- **19路**：完整的标准棋盘。双指张开可放大。

## 难度

- **简单**：几乎随意落子，但会提掉只剩一口气的棋子，常常救自己的棋，也很少让自己陷入危险。适合学习规则。
- **中等**：从当前局面出发，快速模拟几千盘对局直到终局，选择胜率最高的一手（蒙特卡洛搜索），思考约三分之一秒。
- **困难**：同样的搜索，思考约三分之二秒。在大棋盘上，同样的时间能模拟的对局更少，所以电脑会弱一些。

电脑从不填自己的眼。没有让子：所有难度都使用同样的6.5目贴目。

## 小技巧

- 先占角，再占边，最后才是中央：在角上围地需要的棋子最少。
- 有两个分开的眼（棋块内部的空点）的棋块永远不会被提掉。
- 当你的某块棋只剩一口气时，要么马上救，要么放弃；不要往没救的棋里继续添子。
