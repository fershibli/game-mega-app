# 韩国象棋（将棋）

🌐 [English](../../en/games/janggi.md) · [Português](../../pt-BR/games/janggi.md) · [Español](../../es/games/janggi.md) · [Français](../../fr/games/janggi.md) · [Italiano](../../it/games/janggi.md) · [Deutsch](../../de/games/janggi.md) · [Русский](../../ru/games/janggi.md) · [日本語](../../ja/games/janggi.md) · **中文** · [العربية](../../ar/games/janggi.md)

韩国象棋是中国象棋的近亲，在朝鲜半岛已经流传了好几百年。棋盘上没有河界，九宫里的斜线好几种棋子都能走，而且你可以**停一步**不走棋。

**在这部手机上轮流玩：** 两个人也可以不用电脑，互相对战。棋盘不会转动，屏幕会显示轮到谁。

## 棋盘

- 横9条线、竖10条线；棋子放在**交叉点**上。
- 双方各有一个**九宫**（画着X的3×3个交叉点）。在九宫里，棋子也可以沿着X的斜线走。
- 你执**蓝棋**（楚），在下方，先走。电脑执红棋（汉）。
- 将从九宫的**正中间**开始。

## 棋子和记号

每枚棋子上有字和表示走法的小记号：

- **一个点** = 走一步；**两个点** = 象的远跳；
- **箭头** = 走任意远；
- **带横杠的箭头** = 必须隔一个棋子；
- **空心点** = 只能沿九宫斜线走的一步。

| 棋子 | 走法 |
|---|---|
| 将 楚 / 漢（最大的棋子） | 沿九宫的线走一步，斜线也可以。永远不出九宫。 |
| 士（小棋子） | 和将一样：沿九宫的线走一步，不出九宫。 |
| 象 | 先直走一点，再向外斜走两点。路上的点有棋子就不能走。 |
| 马 | 先直走一点，再向外斜走一点。第一点有棋子就不能走。 |
| 车 | 沿着线走任意远，在九宫里也可以沿斜线走。 |
| 包 | 无论走还是吃，都必须**正好隔一个**棋子。不能隔着另一个包，也不能吃包。在九宫里也可以沿斜线隔子跳。 |
| 卒 / 兵（小棋子） | 向前或横走一步，不能后退。在对方九宫里也可以沿斜线向前走。 |

随时点“棋子”按钮，就能看到大图。

## 特殊规则

- **将军**和**将死**与国际象棋一样：将死对方就赢。
- **停一步**：你可以点“停一步”代替走棋，但被将军时不行。如果你的棋子都不能走，就必须停一步。
- **两将对面**（对将）：如果两个将在同一条线上、中间没有棋子，本应用判为**和棋**（传统规则的简化版）。
- 双方接连停一步，也是和棋。

## 在应用里怎么下

1. 点一枚你的蓝棋子，绿点会显示它能走到哪里。
2. 点一个绿点就走过去。吃掉的棋子显示在棋盘的上方和下方。
3. “撤销”会收回你上一步和电脑的应着；“提示”会指出一步好棋。

## 难度

- **简单**：只看一步，经常走错。
- **中等**：看几步。
- **困难**：在一秒之内想得尽量深。只有无棋可走时才停一步。

## 简化的地方

双方都用同一种开局摆法（从左数：马、象、象、马）；不提供传统的马象互换。结束时不算分。同一局面出现**三次**、双方**各走60步没有吃子**、或者双方都没有进攻棋子时，算和棋。

## 小窍门

- 车最强，其次是包和马。
- 包需要别的棋子当“炮架”：开局时先给它准备好。
- 利用九宫斜线：九宫角上的车或包可以攻击对面的角。
