# 小宠物

一个小伙伴住在你手机里一间温馨的小屋里。想什么时候照顾它都可以：不用着急，没有计时，也不会发生任何坏事。

## 第一次来

从十个伙伴中选一个：小猫、小狗、小兔、小鸡、熊猫、青蛙、狐狸、企鹅、仓鼠或乌龟。然后点一个推荐的名字（或自己输入），再点 **领养**。

## 四个条

**开心**、**饱饱**、**精力** 和 **干净** 会非常慢地下降，从满到空大约一天，即使应用关闭也一样。它们永远不会低于 20 %：条开头那段浅色就是最"空"的样子。你的伙伴从不生病、从不离家出走，也从不责怪你。某个条低的时候，它只是看起来有点困或有点饿，冒出一个小小的想法泡泡，见到你依然很开心。

## 可以做什么

- **喂食**：苹果、胡萝卜、小鱼或饼干。每个伙伴都有最爱吃的。
- **摸摸**：用手指抚摸它，会冒出小爱心。
- **亲亲** 和 **挥手**：它会亲回来，也会向你挥手。
- **洗澡**：好多泡泡，洗得干干净净。
- **睡觉**：灯光变暗，精力慢慢恢复。想叫醒时点 **叫醒**。
- **散步**：去花园走一走。
- **玩耍**：石头剪刀布、井字棋（你的标记是爱心，它的是小爪印；它下得很简单，有时会让你赢）或皮球。
- **打扮**：蝴蝶结、帽子、小花或围巾。

## 伙伴和领养

确认之后，随时可以领养另一种伙伴。原来的伙伴会在花园里等你，可以在同一个画面把它叫回来：谁都不会丢。

## 保存

一切都会立刻保存在手机上。关闭应用、重启手机、玩别的游戏，或在设置里点 **新游戏**，都不会删除你的伙伴。卸载应用才会删除。

## 小提示

- 这里没有输赢：想来的时候就来看看它。
- 如果不方便用手指滑动，点 **摸摸** 按钮也可以。
