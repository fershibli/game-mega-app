# 五子棋

🌐 [English](../../en/games/gomoku.md) · [Português](../../pt-BR/games/gomoku.md) · [Español](../../es/games/gomoku.md) · [Français](../../fr/games/gomoku.md) · [Italiano](../../it/games/gomoku.md) · [Deutsch](../../de/games/gomoku.md) · [Русский](../../ru/games/gomoku.md) · [日本語](../../ja/games/gomoku.md) · **中文** · [العربية](../../ar/games/gomoku.md)

双人游戏，在15路棋盘的交叉点上落子。你执黑先行，电脑执白。先在横、竖或斜线上连成五颗或更多棋子的一方获胜。

## 怎么玩

- 点一个交叉点：会显示一颗半透明的棋子。再点一次同一个交叉点就落子；点别的交叉点可以改变主意。
- 最后一手棋上有一个小圆圈，获胜的连线会高亮显示。
- **撤销**会收回你的上一步（以及电脑的应手）。**提示**会标出一个好的交叉点。

## 规则

- 自由规则：连成五子或更多即获胜，六子以上也算。
- **不**使用比赛中对黑棋的禁手限制（三三、四四、长连），所以先走的黑棋有优势。
- 如果棋盘下满，就是平局。

## 难度

- **简单**：选择看起来最好的交叉点，但有时会故意下一步差棋，甚至可能忘记挡住冲四。
- **中等**：一定会把自己的四连成五，也一定会挡住你的四，并且会往前看几步。
- **困难**：看得更深，还会寻找连续冲四取胜的走法，全部在一秒以内完成。

## 小技巧

- **活三**（两端都空着的三连）必须马上挡住，否则会变成挡不住的活四。
- 同时有两个威胁就能获胜：试着用一手棋同时做成冲四和活三。
