# 人生之路

🌐 [English](../../en/games/trail.md) · [Português](../../pt-BR/games/trail.md) · [Español](../../es/games/trail.md) · [Français](../../fr/games/trail.md) · [Italiano](../../it/games/trail.md) · [Deutsch](../../de/games/trail.md) · [Русский](../../ru/games/trail.md) · [日本語](../../ja/games/trail.md) · **中文** · [العربية](../../ar/games/trail.md)

一款二到四人玩的轻松棋盘游戏。掷骰子，走完一生：从棋盘下方的童年，一直走到上方安宁的晚年。路上收集 **爱心**：所有人都到达后，爱心最多的人获胜。没有人会被送回起点，也不会发生坏事：这是散步，不是比赛。

可以和电脑玩（电脑走其他棋子），也可以 **在这部手机上轮流玩**。应用会问有几个人一起玩。

## 棋盘
六片风景，每片是人生的一个阶段（游乐场和学校、城市和大学、办公楼和工坊、房子和花园、港口和山、门廊和果园）：**童年**、**青春**、**工作**、**家庭**、**旅行** 和 **安宁的晚年**。道路从小旗子弯弯曲曲地往上，一直通到小房子。

| 格子 | 会发生什么 |
|---|---|
| ♥ 爱心 | 得到一颗爱心。 |
| 📖 书 | 这个阶段的一个故事：读完点 **继续**。大多数给 1 到 3 颗爱心；有几个会让你走一两格。 |
| 路牌 | 岔路口：**停下** 得 2 颗爱心，**往前走** 前进 3 格。 |
| 普通 | 什么也没有，欣赏风景吧。 |

## 到达
第一个到小房子的人得 **5** 颗爱心，第二个 **3** 颗，第三个 **2** 颗，第四个 **1** 颗。不需要正好掷到点数。所有棋子都到达后游戏结束，最后显示爱心数。

## 小窍门
- 在岔路口停下得 2 颗爱心；早一名到达最多多得 2 颗。快到终点时，如果后面的人跟得很近，往前走可能更划算。
- **简单** 难度下电脑在岔路口随便选；**中等** 和 **困难** 下，只有能拿到更好的到达奖励时它才会赶路。
