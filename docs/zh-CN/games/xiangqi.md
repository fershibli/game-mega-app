# 中国象棋

🌐 [English](../../en/games/xiangqi.md) · [Português](../../pt-BR/games/xiangqi.md) · [Español](../../es/games/xiangqi.md) · [Français](../../fr/games/xiangqi.md) · [Italiano](../../it/games/xiangqi.md) · [Deutsch](../../de/games/xiangqi.md) · [Русский](../../ru/games/xiangqi.md) · [日本語](../../ja/games/xiangqi.md) · **中文** · [العربية](../../ar/games/xiangqi.md)

中国象棋是中国和越南最流行的棋类游戏。两军隔着一条河对阵，谁先困住对方的**将（帅）**谁就赢。

**在这部手机上轮流玩：** 两个人也可以不用电脑，互相对战。棋盘不会转动，屏幕会显示轮到谁。

## 棋盘

- 横9条线、竖10条线。棋子放在**线的交叉点**上，而不是格子里。
- 棋盘中间是**河界**。有些棋子过河以后走法会变。
- 双方各有一个**九宫**：画着X的3×3个交叉点。将（帅）和两个士永远不出九宫。
- 你执**红棋**，在下方，先走。电脑执黑棋。

## 棋子和记号

每枚棋子上写着传统的字，字的四周还有表示走法的小记号，不认识字也能下：

- **一个点** = 朝那个方向走一步；**两个点**连在一起 = 走两步；
- **箭头** = 朝那个方向走任意远；
- **带横杠的箭头** = 要隔一个棋子才能吃子；
- **空心点** = 过河以后才能这样走。

| 棋子 | 记号 | 走法 |
|---|---|---|
| 帅 / 将 | 直向4个点 | 沿着线走一步，只在九宫里。 |
| 仕 / 士 | 斜向4个点 | 斜走一步，只在九宫里。 |
| 相 / 象 | 斜向4对点 | 斜走正好两点（走“田”字）。不能过河，中间的点有棋子就不能走（塞象眼）。 |
| 马 | 8个点 | 先直走一点，再向外斜走一点（走“日”字）。那个方向紧挨着的点有棋子就不能走（蹩马腿）。 |
| 车 | 4个箭头 | 沿着线走任意远。是最强的棋子。 |
| 炮 / 砲 | 4个带横杠的箭头 | 走法和车一样，但**吃子**时必须正好隔一个棋子（哪一方的都行）。 |
| 兵 / 卒 | 前面1个点，两侧2个空心点 | 向前走一步；过河以后也可以横走一步。永远不能后退。 |

随时点“棋子”按钮，就能看到这张表的大图。

## 特殊规则

- **将帅不能照面**：两个将帅不能在中间没有棋子的同一条线上相对。造成这种局面的走法不允许。
- **将军**：你的帅被攻击了，必须解除将军。
- **将死**对方就赢。在中国象棋里，即使没有被将军，**无棋可走**也算**输**（困毙）。

## 在应用里怎么下

1. 点一枚你的红棋子，绿点会显示它能走到哪里（敌方棋子周围的绿圈表示可以吃掉它）。状态栏会说明这是什么棋子、怎么走。
2. 点一个绿点就走过去。
3. “撤销”会收回你上一步和电脑的应着。“提示”用箭头指出一步好棋。
4. 双方吃掉的棋子显示在棋盘的上方和下方。

## 难度

- **简单**：只看一步，经常走错。适合学习。
- **中等**：看几步，不会白白丢子。
- **困难**：在一秒之内想得尽量深。

## 简化的地方

正式规则禁止长将和长捉；这里重复局面一律算**和棋**。同一局面出现**三次**、双方**各走60步没有吃子**、或者双方都没有能进攻的棋子（马、车、炮、兵）时，也算和棋。

## 小窍门

- 早点出车：一个车大约顶两个马。
- 炮吃子需要“炮架”；开局棋子多的时候炮最厉害。
- 让士和象守在帅的身边，它们是帅的保镖。
