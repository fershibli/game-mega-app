# 红心

🌐 [English](../../en/games/hearts.md) · [Português](../../pt-BR/games/hearts.md) · [Español](../../es/games/hearts.md) · [Français](../../fr/games/hearts.md) · [Italiano](../../it/games/hearts.md) · [Deutsch](../../de/games/hearts.md) · [Русский](../../ru/games/hearts.md) · [日本語](../../ja/games/hearts.md) · **中文** · [العربية](../../ar/games/hearts.md)

## 牌
- 用一整副 52 张的牌，每人发 **13 张**。A 最大。
- 赢到的每张 **红心** 算 **1 分**，**黑桃 Q** 算 **13 分**，共 26 分。

## 传牌
每局发牌后，每人选 **3 张** 牌传出去：先传给 **左边**，下一局传给 **右边**，再下一局传给 **对面**，然后有一局不传，再从头开始。点 3 张牌把它们抬起来，再点 **传出3张牌**。收到的牌在第一墩结束前会有圆圈标记。

## 怎么玩
- 手里有 **梅花 2** 的人先出这张牌，开始第一墩。按顺时针方向（向左）轮流出牌。
- **能跟花色就必须跟。** 跟不了可以出任何牌。第一墩里，只要还有别的牌能出，就不能出红心和黑桃 Q。
- 在有人出过红心之前，不能先出红心（除非你手里只剩红心）。
- 第一张牌花色里最大的牌赢这一墩，没有王牌。赢的人下一墩先出。
- 点一张牌它会抬起来，再点一下或点 **出牌**。灰色的牌现在不能出，点一下会告诉你为什么。**提示** 会告诉你出哪张牌（以及传哪 3 张）。出过的牌不能收回。

## 全收
如果你赢到了 **所有红心和黑桃 Q**，你得 0 分，其他每人各得 **26 分**。

## 游戏结束
一局结束时如果有人到了 **100 分**，游戏就结束，**分数最少的人获胜**。

## 难度
电脑看不到扣着的牌，只知道自己的牌、出过的牌、自己传出的牌，以及谁已经没有某种花色。
- **简单：** 随便传 3 张，也常常随便出牌。
- **中等：** 传出黑桃 Q 和大的黑桃、红心；能出比当前最大牌小的牌就出小的；跟不了花色时把 Q 或大红心丢给别人；出小黑桃把 Q 引出来。
- **困难：** 想象很多种看不见的牌的分法，把每张牌试到本局结束，选出得分最少的那张。

## 小窍门
- 早点出完张数少的花色：没有这个花色后，就能丢掉危险的牌。
- 黑桃 Q 还没出来时，留几张小黑桃可以保护自己。
