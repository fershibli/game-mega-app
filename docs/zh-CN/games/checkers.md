# 西洋跳棋

🌐 [English](../../en/games/checkers.md) · [Português](../../pt-BR/games/checkers.md) · [Español](../../es/games/checkers.md) · [Français](../../fr/games/checkers.md) · [Italiano](../../it/games/checkers.md) · [Deutsch](../../de/games/checkers.md) · [Русский](../../ru/games/checkers.md) · [日本語](../../ja/games/checkers.md) · **中文** · [العربية](../../ar/games/checkers.md)

两人对弈的棋类游戏：你对电脑。棋子在深色格子上斜向移动；如果对方棋子紧后方的格子是空的，就可以跳过去吃掉它。走到对面底线的棋子升为**王棋**（会戴上金色王冠）。电脑没有棋子或无路可走时，你就赢了。

## 玩法

- 点一枚你的棋子，它能去的格子会亮起来。再点其中一个。
- **有子必吃。** 能吃子时，可以吃子的棋子会被圈出来。
- 一步连吃多子时，直接点最后的落点。如果有多条路线，就依次点每个落点。
- **撤销**可收回你上一步（以及电脑的回应）。**提示**会给出一步好棋。
- 如果双方各走25步都只动王棋且没有吃子，就判和棋，游戏不会陷入僵局。

## 可选规则

- **巴西跳棋**（8×8，各12子）：普通棋子向前走一格，可以向前或向后吃子。王棋可以“飞”：沿斜线走任意格并远距离吃子。必须吃最多的子。连吃途中只是经过底线的棋子，只有停在底线时才升王。
- **国际跳棋**（10×10，各20子）：规则与巴西跳棋相同，棋盘更大。
- **英式跳棋**（8×8，也叫美式跳棋）：普通棋子只能向前走、向前吃；王棋可向任意斜向走一格。必须吃子，但可以自由选择吃法。刚升王的棋子本步结束。深色先走，所以这里你执深色棋子。
- **意大利跳棋**（8×8，棋盘转过来，你的右手角是可走的格子）：普通棋子只能向前吃，而且不能吃王棋；王棋每次走一格。必须吃最多的子；数量相同时优先用王棋吃，其次吃掉更多的王棋。
- **俄罗斯跳棋**（8×8）：普通棋子也能向后吃，王棋可以飞，吃法自由选择。连吃途中升王的棋子会以王棋身份继续吃。

## 难度

- **简单**：只看两步，偶尔会走得不小心，适合入门。
- **中等**：大约看四步。
- **困难**：在一秒之内尽量往深处想。

## 小技巧

- 尽量让自己最后一排的棋子留在原位，这样电脑就很难升王。
- 中间的棋子比边上的棋子更有力。
- 走之前，先看看这枚棋子下一步会不会被吃掉。
