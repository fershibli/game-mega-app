# 纸牌接龙

**目标：** 克朗代克接龙——把所有牌按花色、从 A 到 K 移到上方的四个收牌堆。

**玩法：** 只需 **点一下牌**。它会自动移到最合适的位置：能放进收牌堆就放进去；否则放到某一列上（颜色交替、点数小一）；否则放到空列（只有 K 可以）。如果哪里都不能放，它会闪一下红色。点一列中间翻开的牌，会连同它上面的牌一起移动。点 **牌堆**（右上角；左手模式在左上角）翻牌；牌堆用完后再点一下，会把翻开的牌重新放回去。**提示** 会框出一个有用的走法；当所有牌都翻开后会出现 **自动完成**，替你走完剩下的牌。

| 难度 | 每次翻牌 | 可翻牌轮数 |
|---|---|---|
| 简单 | 1 张 | 不限 |
| 中等 | 3 张 | 不限 |
| 困难 | 3 张 | 3 轮 |
