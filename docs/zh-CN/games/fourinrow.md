# 四子棋

🌐 [English](../../en/games/fourinrow.md) · [Português](../../pt-BR/games/fourinrow.md) · [Español](../../es/games/fourinrow.md) · [Français](../../fr/games/fourinrow.md) · [Italiano](../../it/games/fourinrow.md) · [Deutsch](../../de/games/fourinrow.md) · [Русский](../../ru/games/fourinrow.md) · [日本語](../../ja/games/fourinrow.md) · **中文** · [العربية](../../ar/games/fourinrow.md)

双人游戏，在一个立着的木架上进行，木架有7列6行圆孔。你执浅色棋子先行，电脑执深色棋子。先把四枚棋子连成一线（横、竖或斜）的一方获胜。

## 怎么玩

- 点一列中的任何位置（从棋盘顶部到底部都可以）：你的棋子会落到最下面的空孔里。
- 满了的列不能再放棋子。如果42个孔全部填满还没有四子连线，就是平局。
- 获胜的连线会高亮显示。
- **撤销**会收回你的上一步（以及电脑的应手）。**提示**会给一个好的列涂上颜色。

## 难度

- **简单**：能赢时一定会赢，通常会挡住你，其余时候只往前看两步，有时还会随便投一枚棋子。
- **中等**：往前看六步。
- **困难**：在约三分之二秒内尽量往前看。很难战胜。

## 小技巧

- 中间那一列最有价值：经过它的四子连线最多。
- 投子之前，先检查电脑会不会在这枚棋子正上方投子获胜。
- 同时制造两个威胁，比如一个正好在另一个的上方：电脑只能挡住一个。
