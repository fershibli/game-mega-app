# Regras para quem trabalha neste repositório

Este arquivo vale para pessoas e para qualquer agente automático. Antes de mexer em qualquer coisa, leia:

1. [`rules/`](rules/README.md): as regras de qualidade do projeto. Elas são obrigatórias.
2. [`backlog/HANDOFF.md`](backlog/HANDOFF.md): como o código está organizado e o passo a passo de um PR.
3. [`backlog/specs.md`](backlog/specs.md): o que fazer, item por item.

Se uma regra parecer atrapalhar, não a ignore: pergunte à dona do produto e registre a decisão aqui.
